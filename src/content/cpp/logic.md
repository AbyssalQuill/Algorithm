# 比较与逻辑

> [!目标]
> 读完这一课，你应该能用比较运算得出“成立”或“不成立”，能用 `&&`、`||`、`!` 把多个条件组合起来，并且知道 `=` 与 `==` 的区别、区间条件的正确写法，以及运算符的优先级。

## 比较运算

要让程序做出判断，首先得能比较两个值。C++ 提供了六种比较运算符：

| 运算符 | 含义 |
| :-: | :-- |
| `==` | 等于 |
| `!=` | 不等于 |
| `>`、`<` | 大于、小于 |
| `>=`、`<=` | 大于或等于、小于或等于 |

比较的结果只有两种：成立或不成立。成立时得到真值 `true`，输出出来是 `1`；不成立时得到假值 `false`，输出出来是 `0`。

```cpp frag
int a=5,b=3;
cout<<(a>b)<<" "<<(a<b)<<" "<<(a==b)<<" "<<(a!=b)<<endl;
```

```output
1 0 0 1
```

## 等号与赋值号

初学者最容易犯的错误，是把比较用的 `==` 写成赋值用的 `=`。两者含义完全不同：`=` 是把右边的值存进左边的变量，`==` 才是询问“两边相不相等”。

麻烦在于，写错之后程序并不会报错，而是悄悄地改变了行为：

```cpp frag
int a=5;
if (a=3){
    cout<<"进来了，a="<<a<<endl;
}
```

```output
进来了，a=3
```

`a=3` 先把 3 存进了 `a`，而这条赋值表达式本身的值也是 3，非零就被当作“真”，所以条件成立；与此同时 `a` 也被悄悄改成了 3。

> [!注意] 判断是否相等，请逐字检查是不是两个等号
> 有些人习惯把常量写在左边，写成 `5==a`。这样万一漏写了一个等号，变成 `5=a`，编译器会直接报错，而不是让错误悄悄溜过去。

## 逻辑运算：组合多个条件

一个条件往往不够用，比如“成绩及格并且出勤达标”。逻辑运算符就是用来把几个条件拼在一起的：

| 运算符 | 读作 | 什么时候为真 |
| :-: | :-: | :-- |
| `&&` | 并且 | 左右两个条件同时成立 |
| `\|\|` | 或者 | 左右两个条件至少有一个成立 |
| `!` | 非 | 条件不成立时为真，成立时为假 |

```cpp frag
int x=15;
cout<<(x>10&&x<20)<<" "<<(x<10||x>12)<<" "<<!(x>10)<<endl;
```

```output
1 1 0
```

## 表示“在某个范围内”

在数学里，我们会写 `0≤x≤10` 表示 `x` 在 0 到 10 之间。C++ 里却不能这样写，必须拆成两个条件，再用 `&&` 连接起来：

```cpp frag
int x=20;
cout<<(0<=x<=10)<<endl;
cout<<(0<=x&&x<=10)<<endl;
```

```output
1
0
```

第一种写法得到了错误的 1。原因是 C++ 按从左到右的顺序计算：先算 `0<=x`，结果为 1；再拿这个 1 去和 10 比较，`1<=10` 成立，于是整个式子得到 1。程序没有任何报错，答案却是错的。

## 短路求值

使用 `&&` 时，如果左边的条件已经不成立，整个式子的结果就已经确定为假，右边的部分不会再被执行。同样，`||` 的左边如果已经成立，右边也会被跳过。这叫短路求值。

```cpp frag
int a=0,b=0,c=0;
if (a!=0&&++b>0){ }
if (a==0||++c>0){ }
cout<<b<<" "<<c<<endl;
```

```output
0 0
```

两个条件中右边的 `++b` 和 `++c` 都没有被执行，所以 `b` 和 `c` 仍然是 0。

这个特性可以用来做“先检查，再使用”，从而避免出错。例如 `y!=0&&x/y>1` 会先确认除数不是 0 再做除法，`i<n&&a[i]>0` 会先确认下标没有越界，再去访问数组元素。

## 运算符的优先级

当一个式子里出现了多种运算符，C++ 会按照优先级决定先算哪个，大致顺序如下，越靠前越先计算：

| 顺序 | 运算符 |
| :-: | :-- |
| 1 | `!` |
| 2 | `*` `/` `%`，然后是 `+` `-` |
| 3 | `<` `<=` `>` `>=` |
| 4 | `==` `!=` |
| 5 | `&&` |
| 6 | `\|\|` |
| 7 | `=`（赋值最后进行） |

> [!提示] 拿不准时就加括号
> 括号里的内容永远最先计算。与其费力去记优先级，不如用括号把意图写清楚：`(a>b)||(a<c&&b==d)` 要比不加括号的写法容易读得多。

## 关于“真”与“假”

在 C++ 中，**数值 0 表示假，其余任何数都表示真**。因此 `if (n)` 等价于 `if (n!=0)`，`if (!n)` 等价于 `if (n==0)`。竞赛代码里经常能看到这种简写。

> [!思考] 判断字符 `c` 是不是大写字母
> 提示：字符在计算机里本质上是数字，而 `'A'` 到 `'Z'` 这 26 个大写字母是连续排列的。

> [!答案] 参考写法
> 用刚才学的区间写法，判断它是否落在 `'A'` 和 `'Z'` 之间：
>
> ```cpp frag
> char c='G';
> cout<<(c>='A'&&c<='Z')<<endl;
> ```
>
> ```output
> 1
> ```

> [!小结]
> 比较的结果是 1 或 0。`==` 用来比较，`=` 用来赋值，二者不能混淆。多个条件用 `&&`、`||`、`!` 组合，范围条件要拆成两个比较再相连。短路求值让我们可以放心地把“检查”放在前面，优先级拿不准时用括号表明意图。
