# 比较与逻辑

> [!目标]
> - 会用 `==、!=、>、<、>=、<=` 做比较，知道结果是 1 或 0
> - 分清 `=`（赋值）和 `==`（比较）
> - 会用 `&&`、`||`、`!` 组合条件，写对“在某个区间里”的判断
> - 理解短路求值，知道常见运算符的优先级

## 比较运算：结果只有“对”和“错”

| 运算符 | 含义 |
| :-: | :-- |
| `==` | 等于 |
| `!=` | 不等于 |
| `>`  `<` | 大于、小于 |
| `>=`  `<=` | 大于等于、小于等于 |

比较的结果是一个**真假值**：成立是 `true`（输出时显示 `1`），不成立是 `false`（显示 `0`）。

```cpp frag
int a=5,b=3;
cout<<(a>b)<<" "<<(a<b)<<" "<<(a==b)<<" "<<(a!=b)<<endl;
```

```output
1 0 0 1
```

## 最经典的错误：`=` 和 `==`

- `=` 是**赋值**：把右边放进左边。
- `==` 是**比较**：问“两边相等吗”。

把 `==` 写成 `=`，程序不会报错，却会悄悄地出错：

```cpp frag
int a=5;
if (a=3){
    cout<<"进来了，a="<<a<<endl;
}
```

```output
进来了，a=3
```

`a=3` 先把 3 放进了 `a`，而这句话本身的值是 3（非零就算“真”），于是条件成立了。

> [!注意] 养成习惯：判断相等一定检查是两个等号
> 想写“`a` 等于 5”，是 `a==5`。有人喜欢把常数写在前面（`5==a`），这样万一漏写一个 `=`，编译器会直接报错提醒你。

## 逻辑运算：把多个条件拼起来

| 运算符 | 读作 | 什么时候为真 |
| :-: | :-: | :-- |
| `&&` | 并且 | 两边**都**为真 |
| `\|\|` | 或者 | 两边**至少一个**为真 |
| `!` | 不是 | 把真变假、假变真 |

```cpp frag
int x=15;
cout<<(x>10&&x<20)<<" "<<(x<10||x>12)<<" "<<!(x>10)<<endl;
```

```output
1 1 0
```

## 判断“在某个区间里”的正确写法

数学里写 `0<=x<=10`，在 C++ 里**不能这样写**，要拆成两个条件再用 `&&` 连起来：

```cpp frag
int x=20;
cout<<(0<=x<=10)<<endl;
cout<<(0<=x&&x<=10)<<endl;
```

```output
1
0
```

第一种写法为什么得到 1？它从左往右算：先算 `0<=x`，得到 `1`；再算 `1<=10`，又成立，得 `1`。程序完全没报错，答案却是错的。

## 短路求值：不用算的就不算

`&&` 的左边如果已经是假，整个式子必然是假，**右边根本不会去执行**。`||` 的左边如果已经是真，右边同理。

```cpp frag
int a=0,b=0,c=0;
if (a!=0&&++b>0){ }
if (a==0||++c>0){ }
cout<<b<<" "<<c<<endl;
```

```output
0 0
```

两次的右边（`++b`、`++c`）都没有被执行，所以 `b` 和 `c` 还是 0。

这个特性很有用，可以用来“先检查再使用”，避免出错：

- `y!=0&&x/y>1`：先确认 `y` 不是 0，再做除法。
- `i<n&&a[i]>0`：先确认下标没超出范围，再去读 `a[i]`。

## 运算优先级

多个运算符写在一起时，先算谁，后算谁？从高到低大致是：

| 顺序 | 运算符 |
| :-: | :-- |
| 1 | `!` |
| 2 | `*` `/` `%`，然后 `+` `-` |
| 3 | `<` `<=` `>` `>=` |
| 4 | `==` `!=` |
| 5 | `&&` |
| 6 | `\|\|` |
| 7 | `=`（赋值，最后算） |

> [!提示] 记不住也没关系：多加括号
> 谁先谁后拿不准，就加括号，括号里的永远最先算。可读性也更好：`(a>b)||(a<c&&b==d)` 比不加括号清楚得多。

## 真假值的小规矩

在 C++ 里，**0 是假，其他任何数都是真**。所以 `if (n)` 等价于 `if (n!=0)`，`if (!n)` 等价于 `if (n==0)`。竞赛代码里经常这样简写。

> [!思考] 判断字符 `c` 是不是大写字母
> 提示：字符在内部就是一个数字，大写字母 `'A'` 到 `'Z'` 是连续的一段。

> [!答案] 参考写法
> 用区间判断：
>
> ```cpp frag
> char c='G';
> cout<<(c>='A'&&c<='Z')<<endl;
> ```
>
> ```output
> 1
> ```

> [!小结]
> - 比较的结果是 1（真）或 0（假）；`==` 是比较，`=` 是赋值，别写混。
> - `&&` 并且、`||` 或者、`!` 取反；区间要拆成两个条件：`0<=x&&x<=10`。
> - 短路求值：左边能决定结果时，右边不执行。
> - 优先级拿不准就加括号。
