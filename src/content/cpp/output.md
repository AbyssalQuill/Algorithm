# 输出

> [!目标]
> 读完这一课，你应该能用 `cout` 和 `printf` 输出文字与计算结果，能控制换行和小数位数，并且知道怎样输出引号这类特殊字符。

## 用 cout 输出

`cout` 是 C++ 里最常用的输出方式。可以把 `<<` 想象成一根水管，把右边的内容一路“送”到屏幕上；需要输出多项内容时，把它们用 `<<` 依次连起来就行。

```cpp title="cout.cpp"
#include <bits/stdc++.h>
using namespace std;
int main(){
    cout<<"Hello"<<" "<<"C++"<<endl;
    cout<<123<<endl;
    cout<<1+2<<endl;
    cout<<"1+2="<<1+2<<endl;
    return 0;
}
```

```output
Hello C++
123
3
1+2=3
```

这个例子里有一处区别值得留意：带双引号的内容是文字，会原样输出，所以 `"1+2="` 显示的就是这四个字符；不带引号的 `1+2` 是一个算式，程序会先算出结果，再把结果 3 输出。

## 换行：`\n` 与 `endl`

如果希望后面的内容出现在下一行，有两种写法，效果相同：

```cpp frag
cout<<"第一行\n第二行\n";
cout<<"第三行"<<endl;
```

```output
第一行
第二行
第三行
```

它们的差别在于效率。`endl` 在换行之外，还会立刻把缓冲区里尚未显示的内容刷新到屏幕上，这个额外的动作在输出行数很多时会明显拖慢程序；`\n` 只负责换行，开销小得多。

> [!竞赛] 大量输出时用 `\n`
> 平时练习用 `endl` 没有问题。一旦需要输出几万行数据，改用 `'\n'` 或 `"\n"` 能节省不少时间，有的题目甚至会因此从超时变成通过。

## 转义字符

引号本身用来标出文字的边界，那么要输出一个引号该怎么办？办法是在它前面加一个反斜杠，表示“这个符号就是它字面的意思”。这类以反斜杠开头的写法叫作转义字符。

| 写法 | 含义 |
| :-: | :-- |
| `\n` | 换行 |
| `\t` | 制表符，大致相当于按一次 Tab 键，常用来对齐 |
| `\"` | 一个双引号 |
| `\\` | 一个反斜杠 |

```cpp frag
cout<<"姓名\t成绩\n";
cout<<"小明\t95\n";
cout<<"他说：\"你好\"\n";
cout<<"路径：C:\\data\n";
```

```output
姓名	成绩
小明	95
他说："你好"
路径：C:\data
```

## printf

`printf` 来自 C 语言，在算法竞赛里同样非常常见。它的做法是先写一个带“占位符”的模板，再按顺序把要输出的内容填进去。占位符以百分号开头，不同类型的数据对应不同的占位符：

| 占位符 | 对应的数据 |
| :-: | :-- |
| `%d` | 整数（`int`） |
| `%lld` | 大整数（`long long`） |
| `%f` | 小数（`double`） |
| `%c` | 单个字符 |
| `%s` | 一段文字（C 风格字符串） |

```cpp frag
printf("Hello\n");
printf("%d\n",42);
printf("%d+%d=%d\n",1,2,1+2);
printf("%.2f\n",3.14159);
printf("%c\n",'A');
printf("%lld\n",1234567890123LL);
```

```output
Hello
42
1+2=3
3.14
A
1234567890123
```

和 `cout` 不同，`printf` 不会自动换行，需要换行时要自己在模板里写上 `\n`。

## 控制小数的位数

题目经常要求“保留两位小数”，两种输出方式都有对应的办法：

```cpp frag
double x=3.14159;
cout<<x<<endl;
cout<<fixed<<setprecision(2)<<x<<endl;
printf("%.3f\n",x);
```

```output
3.14159
3.14
3.142
```

`printf` 的写法最直观：`%.3f` 表示小数点后保留 3 位。`cout` 需要两个配合使用，`fixed` 规定按小数点后的位数计算，`setprecision(2)` 指定位数是 2。这两项设置一旦生效，会一直保持到被改变为止。

> [!注意] 只写 `setprecision` 而不写 `fixed`，含义会变
> 不加 `fixed` 时，括号里的数字表示的是“一共保留几位有效数字”，而不是小数点后几位：
>
> ```cpp frag
> double x=3.14159;
> cout<<setprecision(2)<<x<<endl;
> ```
>
> ```output
> 3.1
>```
>
> 想要“小数点后几位”，务必同时写上 `fixed`。

## 练习

> [!思考] 只用一条 `cout` 语句，输出下面这个三角形
> ```text
> *
> **
> ***
> ```

> [!答案] 参考写法
> 把换行符直接写进要输出的文字里：
>
> ```cpp frag
> cout<<"*\n**\n***\n";
> ```
>
> ```output
> *
> **
> ***
>```

> [!小结]
> 输出的核心是 `cout<<` 和 `printf`：前者用 `<<` 连接要输出的内容，后者按占位符填空。换行用 `\n` 或 `endl`，数据量大时 `\n` 更快；需要输出引号、反斜杠等特殊字符时使用转义字符；控制小数位数则用 `%.2f` 或 `fixed` 加 `setprecision`。
