# 输出：让程序说话

> [!目标]
> - 会用 `cout` 输出文字、数字和算式的结果
> - 分清换行的两种写法：`\n` 和 `endl`
> - 会用转义字符输出引号、制表符
> - 会用 `printf`，并能控制“保留几位小数”

## cout：最常用的输出

`cout<<` 可以想象成：把右边的东西“倒向”屏幕。多个东西可以连着倒，用 `<<` 隔开。

```cpp title="cout.cpp"
#include <bits/stdc++.h>
using namespace std;
int main(){
    cout<<"Hello"<<" "<<"C++"<<endl;
    cout<<123<<endl;
    cout<<1+2<<endl;
    cout<<"1+2="<<1+2<<endl;
    return 0;
}
```

```output
Hello C++
123
3
1+2=3
```

注意区分两种东西：

- **带双引号**的是文字，原样输出：`"1+2="` 输出的就是 `1+2=` 这几个字符。
- **不带引号**的是数字或算式，先算出结果再输出：`1+2` 输出的是 `3`。

## 换行：`\n` 和 `endl`

想让后面的内容出现在下一行，有两种写法：

```cpp frag
cout<<"第一行\n第二行\n";
cout<<"第三行"<<endl;
```

```output
第一行
第二行
第三行
```

两种写法效果一样，区别在速度：`endl` 除了换行，还会**立刻把缓冲区里的内容推到屏幕上**（刷新），输出很多行时会明显变慢；`\n` 只换行。

> [!竞赛] 输出很多行时，用 `\n`
> 平时练习用 `endl` 没问题；一旦要输出几万行，换成 `'\n'` 或 `"\n"`，能省下不少时间。

## 转义字符：输出特殊的符号

引号本身要用来“包住”文字，那想输出一个引号怎么办？在它前面加一个反斜杠 `\`，告诉程序“这个符号当普通字符用”。

| 写法 | 含义 |
| :-: | :-- |
| `\n` | 换行 |
| `\t` | 制表符（按一下 Tab 键那么宽，用来对齐） |
| `\"` | 一个双引号 |
| `\\` | 一个反斜杠 |

```cpp frag
cout<<"姓名\t成绩\n";
cout<<"小明\t95\n";
cout<<"他说：\"你好\"\n";
cout<<"路径：C:\\data\n";
```

```output
姓名	成绩
小明	95
他说："你好"
路径：C:\data
```

## printf：另一种输出方式

`printf` 是 C 语言留下来的写法，竞赛里非常常见。它的思路是：**先写一个带“占位符”的模板，再把要输出的东西依次填进去**。

| 占位符 | 填进去的是 | 例子 |
| :-: | :-- | :-- |
| `%d` | 整数 `int` | `printf("%d",42)` |
| `%lld` | 大整数 `long long` | `printf("%lld",x)` |
| `%f` | 小数 `double` | `printf("%f",3.5)` |
| `%c` | 一个字符 | `printf("%c",'A')` |
| `%s` | 一段文字（C 风格字符串） | `printf("%s","hi")` |

```cpp frag
printf("Hello\n");
printf("%d\n",42);
printf("%d+%d=%d\n",1,2,1+2);
printf("%.2f\n",3.14159);
printf("%c\n",'A');
printf("%lld\n",1234567890123LL);
```

```output
Hello
42
1+2=3
3.14
A
1234567890123
```

`printf` 不会自动换行，要换行得自己写 `\n`。

## 保留几位小数

题目经常要求“保留 2 位小数”。两种写法都要会：

```cpp frag
double x=3.14159;
cout<<x<<endl;
cout<<fixed<<setprecision(2)<<x<<endl;
printf("%.3f\n",x);
```

```output
3.14159
3.14
3.142
```

- `printf("%.3f")`：`%.3f` 的意思是“小数点后保留 3 位”，最直观。
- `cout<<fixed<<setprecision(2)`：`fixed` 表示“按小数点后的位数算”，`setprecision(2)` 表示 2 位。**设置一次，后面一直有效**。

> [!注意] 只写 `setprecision`、不写 `fixed`，含义会变
> 不加 `fixed` 时，数字表示的是“一共几位有效数字”：
>
> ```cpp frag
> double x=3.14159;
> cout<<setprecision(2)<<x<<endl;
> ```
>
> ```output
> 3.1
> ```
>
> 想要“小数点后几位”，务必带上 `fixed`。

## 练一练

> [!思考] 只用一条 `cout` 语句，输出下面的三角形
> ```text
> *
> **
> ***
> ```

> [!答案] 参考写法
> 把换行 `\n` 直接写进文字里：
>
> ```cpp frag
> cout<<"*\n**\n***\n";
> ```
>
> ```output
> *
> **
> ***
> ```

> [!小结]
> - 用 `cout<<…<<…;` 连着输出；带引号的是文字，不带引号的先算再输出。
> - 换行用 `\n` 或 `endl`；大量输出时 `\n` 更快。
> - `\"`、`\\`、`\t` 是常用的转义字符。
> - `printf("%d")` 是“模板 + 填空”；保留小数用 `%.2f` 或 `fixed<<setprecision(2)`。
