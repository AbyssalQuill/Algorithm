# 二维数组

> [!目标]
> 读完这一课，你应该理解二维数组就是带有行和列的表格，会声明、读入、遍历它，会按行按列处理数据、处理对角线，并且能用方向数组判断一个位置的上下左右是否越界。

## 带有行和列的数组

一维数组是一排数据，二维数组则是一张表格：既有行，也有列，要找到其中某一格，需要同时给出两个下标，写成 `a[行][列]`。

```cpp frag
int a[2][3]={{1,2,3},{4,5,6}};
cout<<a[0][2]<<" "<<a[1][0]<<endl;
```

```output
3 4
```

`int a[2][3]` 声明了一个 2 行 3 列的表格，行和列的下标同样都是从 0 开始：

| | 第 0 列 | 第 1 列 | 第 2 列 |
| :-: | :-: | :-: | :-: |
| **第 0 行** | 1 | 2 | 3 |
| **第 1 行** | 4 | 5 | 6 |

## 用双重循环读入与输出

遍历二维数组要用两层循环：外层控制行，内层控制这一行里的各列。下面的程序读入一个 `n` 行 `m` 列的矩阵，再输出它的转置，也就是把行和列互换：

```cpp title="transpose.cpp"
#include <bits/stdc++.h>
using namespace std;
const int N=105;
int a[N][N];
int main(){
    int n,m;
    cin>>n>>m;
    for (int i=0;i<n;i++){
        for (int j=0;j<m;j++){
            cin>>a[i][j];
        }
    }
    for (int j=0;j<m;j++){
        for (int i=0;i<n;i++){
            cout<<a[i][j]<<" ";
        }
        cout<<endl;
    }
    return 0;
}
```

```input
2 3
1 2 3
4 5 6
```

```output
1 4
2 5
3 6
```

读入时，外层是行、内层是列；输出转置矩阵时，只是把两层循环的次序对调，外层变成列，内层变成行，就得到了行列互换的结果。

## 按行、按列统计

同样的遍历方法，可以求每一行的和，也可以求每一列的和。区别只在于哪一层循环负责累加，哪一层决定输出的时机：

```cpp frag
int a[2][3]={{1,2,3},{4,5,6}};
for (int i=0;i<2;i++){
    int s=0;
    for (int j=0;j<3;j++){
        s+=a[i][j];
    }
    cout<<s<<" ";
}
cout<<endl;
for (int j=0;j<3;j++){
    int s=0;
    for (int i=0;i<2;i++){
        s+=a[i][j];
    }
    cout<<s<<" ";
}
cout<<endl;
```

```output
6 15
5 7 9
```

## 对角线

对于行数和列数相同的方阵，有两条对角线：从左上角到右下角的叫主对角线，元素的行下标等于列下标，即 `a[i][i]`；从右上角到左下角的叫副对角线，元素满足 `a[i][n-1-i]`。

```cpp frag
int a[3][3]={{1,2,3},{4,5,6},{7,8,9}};
int s1=0,s2=0;
for (int i=0;i<3;i++){
    s1+=a[i][i];
    s2+=a[i][2-i];
}
cout<<s1<<" "<<s2<<endl;
```

```output
15 15
```

## 方向数组

走迷宫、处理棋盘这类问题，经常需要从某个格子 `(x,y)` 出发，朝上下左右走一步。如果把四个方向各写一遍，代码会非常啰嗦，更好的办法是用两个数组把每个方向在行、列上的变化量记下来，再用循环依次处理四个方向。

```cpp frag
int dx[4]={-1,1,0,0};
int dy[4]={0,0,-1,1};
int n=3;
int x=0,y=0,cnt=0;
for (int d=0;d<4;d++){
    int nx=x+dx[d],ny=y+dy[d];
    if (nx>=0&&nx<n&&ny>=0&&ny<n){
        cnt++;
    }
}
cout<<cnt<<endl;
```

```output
2
```

`dx` 和 `dy` 的四个位置依次对应上、下、左、右：行坐标分别减 1、加 1、不变、不变，列坐标分别不变、不变、减 1、加 1。上面的程序要回答的问题是：在 3×3 的棋盘上，左上角 `(0,0)` 的上下左右四个方向里，有几个没有走出棋盘？只有向下和向右两个，所以结果是 2。

> [!竞赛] 方向数组是搜索类题目的基本功
> 之后学习深度优先搜索、广度优先搜索时，走迷宫、数连通块这类问题几乎都离不开这套写法：用 `dx`、`dy` 枚举四个方向，再判断新的坐标有没有越界。现在最好把它写得熟练。

## 综合例子：蛇形方阵

把 1 到 n² 按顺时针螺旋的顺序填进 n×n 的方阵里。可以这样想：一直朝着当前方向走，**走不下去的时候（出界，或者前面的格子已经填过）就向右转**，方向的顺序是右、下、左、上，用 `d=(d+1)%4` 让它循环。

```cpp title="snake.cpp"
#include <bits/stdc++.h>
using namespace std;
int a[15][15];
int main(){
    int n;
    cin>>n;
    int dx[4]={0,1,0,-1};
    int dy[4]={1,0,-1,0};
    int x=0,y=0,d=0;
    for (int k=1;k<=n*n;k++){
        a[x][y]=k;
        int nx=x+dx[d],ny=y+dy[d];
        if (nx<0||nx>=n||ny<0||ny>=n||a[nx][ny]!=0){
            d=(d+1)%4;
            nx=x+dx[d];
            ny=y+dy[d];
        }
        x=nx;
        y=ny;
    }
    for (int i=0;i<n;i++){
        for (int j=0;j<n;j++){
            cout<<a[i][j]<<" ";
        }
        cout<<endl;
    }
    return 0;
}
```

```input
3
```

```output
1 2 3
8 9 4
7 6 5
```

> [!注意] 写二维数组的循环时，先想清楚两个下标各自的范围
> `a[i][j]` 中，`i` 最大是 `n-1`，`j` 最大是 `m-1`。双重循环的外层应该用行数，内层用列数，千万别写反，否则要么读不全，要么越界。

> [!小结]
> 二维数组用 `a[行][列]` 访问，遍历时用双重循环，外层行、内层列。主对角线是 `a[i][i]`，副对角线是 `a[i][n-1-i]`。需要朝四个方向走的问题，用 `dx`、`dy` 两个方向数组配合越界判断，这是之后学习搜索算法的基础。
