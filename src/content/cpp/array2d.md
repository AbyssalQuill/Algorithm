# 二维数组

> [!目标]
> - 理解二维数组：像表格一样，有行和列
> - 会声明、读入、遍历、按行按列处理
> - 会处理对角线
> - 认识方向数组，会判断“某个位置的上下左右有没有出界”

## 二维数组：表格

一维数组是一排盒子，**二维数组**就是一张表格：有“行”和“列”，用两个下标 `a[行][列]` 找到其中一格。

```cpp frag
int a[2][3]={{1,2,3},{4,5,6}};
cout<<a[0][2]<<" "<<a[1][0]<<endl;
```

```output
3 4
```

`int a[2][3]` 表示 2 行 3 列，下标同样从 0 开始：

| | 第 0 列 | 第 1 列 | 第 2 列 |
| :-: | :-: | :-: | :-: |
| **第 0 行** | 1 | 2 | 3 |
| **第 1 行** | 4 | 5 | 6 |

## 读入和输出：双重循环

遍历二维数组，外层循环管行，内层循环管列。读入一个 `n` 行 `m` 列的矩阵，再输出它的**转置**（行变列、列变行）：

```cpp title="transpose.cpp"
#include <bits/stdc++.h>
using namespace std;
const int N=105;
int a[N][N];
int main(){
    int n,m;
    cin>>n>>m;
    for (int i=0;i<n;i++){
        for (int j=0;j<m;j++){
            cin>>a[i][j];
        }
    }
    for (int j=0;j<m;j++){
        for (int i=0;i<n;i++){
            cout<<a[i][j]<<" ";
        }
        cout<<endl;
    }
    return 0;
}
```

```input
2 3
1 2 3
4 5 6
```

```output
1 4
2 5
3 6
```

输出时只是把两层循环的**顺序对调**了：外层变成列、内层变成行。

## 按行、按列处理

求每一行的和、每一列的和：

```cpp frag
int a[2][3]={{1,2,3},{4,5,6}};
for (int i=0;i<2;i++){
    int s=0;
    for (int j=0;j<3;j++){
        s+=a[i][j];
    }
    cout<<s<<" ";
}
cout<<endl;
for (int j=0;j<3;j++){
    int s=0;
    for (int i=0;i<2;i++){
        s+=a[i][j];
    }
    cout<<s<<" ";
}
cout<<endl;
```

```output
6 15
5 7 9
```

## 对角线

对一个 `n×n` 的方阵：

- **主对角线**（左上到右下）：`a[i][i]`
- **副对角线**（右上到左下）：`a[i][n-1-i]`

```cpp frag
int a[3][3]={{1,2,3},{4,5,6},{7,8,9}};
int s1=0,s2=0;
for (int i=0;i<3;i++){
    s1+=a[i][i];
    s2+=a[i][2-i];
}
cout<<s1<<" "<<s2<<endl;
```

```output
15 15
```

## 方向数组：走上下左右

迷宫、棋盘、图形填数一类的题，经常需要从某个格子 `(x,y)` 往**上下左右**走一步。与其写四段几乎一样的代码，不如用两个数组把“四个方向”存起来：

```cpp frag
int dx[4]={-1,1,0,0};
int dy[4]={0,0,-1,1};
int n=3;
int x=0,y=0,cnt=0;
for (int d=0;d<4;d++){
    int nx=x+dx[d],ny=y+dy[d];
    if (nx>=0&&nx<n&&ny>=0&&ny<n){
        cnt++;
    }
}
cout<<cnt<<endl;
```

```output
2
```

四个方向依次是：上（行−1）、下（行+1）、左（列−1）、右（列+1）。上面的代码问的是：**在 3×3 的棋盘里，左上角 `(0,0)` 的四周，有几个格子没出界？** 只有往下和往右两个，所以是 2。

> [!竞赛] 这是后面“搜索”的基本功
> 以后学 DFS、BFS（走迷宫、数岛屿），几乎每道题都靠这一套：用 `dx、dy` 枚举四个方向，再判断新坐标有没有出界。现在先把它写熟。

## 综合例子：蛇形方阵

把 1 到 n² 按“顺时针螺旋”填进 `n×n` 的方阵。思路：一直朝着一个方向走，**走不通了（出界，或者前面的格子已经填过）就右转**，方向顺序是：右、下、左、上，用 `d=(d+1)%4` 轮着换。

```cpp title="snake.cpp"
#include <bits/stdc++.h>
using namespace std;
int a[15][15];
int main(){
    int n;
    cin>>n;
    int dx[4]={0,1,0,-1};
    int dy[4]={1,0,-1,0};
    int x=0,y=0,d=0;
    for (int k=1;k<=n*n;k++){
        a[x][y]=k;
        int nx=x+dx[d],ny=y+dy[d];
        if (nx<0||nx>=n||ny<0||ny>=n||a[nx][ny]!=0){
            d=(d+1)%4;
            nx=x+dx[d];
            ny=y+dy[d];
        }
        x=nx;
        y=ny;
    }
    for (int i=0;i<n;i++){
        for (int j=0;j<n;j++){
            cout<<a[i][j]<<" ";
        }
        cout<<endl;
    }
    return 0;
}
```

```input
3
```

```output
1 2 3
8 9 4
7 6 5
```

> [!注意] 二维数组也要“多开几个”，也要先想清楚下标范围
> `a[i][j]` 的行下标最大是 `n-1`，列下标最大是 `m-1`。写双重循环时，外层上限用行数，内层上限用列数，别写反。

> [!小结]
> - 二维数组 `a[行][列]`，用双重循环遍历：外层行、内层列。
> - 对角线：`a[i][i]` 和 `a[i][n-1-i]`。
> - 方向数组 `dx、dy` 加上“是否出界”的判断，是搜索类题目的基本功。
