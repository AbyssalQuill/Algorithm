# for 循环

> [!目标]
> 读完这一课，你应该能看懂 `for` 循环的四个组成部分，会写正序、倒序和指定步长的循环，会用循环做累加和累乘，并且知道几个常见的错误。

## 为什么需要循环

如果要输出 1 到 100，难道要写一百条输出语句吗？程序擅长的恰恰是重复。**循环**让同一段代码按要求重复执行很多次，而我们只需要把它写一遍。`for` 是最常用的一种循环，特别适合“已经知道要重复几次”的情形。

```cpp title="for.cpp"
#include <bits/stdc++.h>
using namespace std;
int main(){
    for (int i=1;i<=5;i++){
        cout<<i<<" ";
    }
    cout<<endl;
    return 0;
}
```

```output
1 2 3 4 5
```

## for 循环的四个组成部分

`for` 的括号里有三个用分号隔开的部分，再加上花括号里的循环体，一共是四个部分：

```cpp noverify
for (初值; 条件; 更新){
    循环体
}
```

以 `for (int i=1;i<=5;i++)` 为例，它们各自的职责如下：

| 部分 | 例子 | 何时执行 |
| :-- | :-- | :-- |
| 初值 | `int i=1` | 循环刚开始时执行，并且只执行一次 |
| 条件 | `i<=5` | 每一轮开始之前检查，成立才进入循环体，不成立则结束整个循环 |
| 循环体 | `{ ... }` | 条件成立时执行 |
| 更新 | `i++` | 每一轮循环体执行完之后执行，然后回到条件，再检查一次 |

下面用 1 加到 3 来演示完整的过程。请留意 `for` 这一行会被反复回来执行：第一次是执行初值并检查条件，之后每次回来则是先做更新，再检查条件。

```trace
int sum=0;                       //@s1
for (int i=1;i<=3;i++){          //@s2
    sum=sum+i;                   //@s3
}
cout<<sum;                       //@s4
---
s1 | sum=0 |  | 先准备一个变量 sum 用来累加，初始值是 0。
s2 | sum=0; i=1 |  | 进入循环：先执行初值 i=1，再检查条件 1<=3，成立，进入循环体。
s3 | sum=1; i=1 |  | 循环体里执行 sum=sum+i，也就是 0+1，sum 变成 1。
s2 | sum=1; i=2 |  | 循环体结束，先执行更新 i++，i 变成 2，再检查 2<=3，成立，继续下一轮。
s3 | sum=3; i=2 |  | sum=1+2，变成 3。
s2 | sum=3; i=3 |  | 更新后 i 变成 3，检查 3<=3，仍然成立。
s3 | sum=6; i=3 |  | sum=3+3，变成 6。
s2 | sum=6; i=4 |  | 更新后 i 变成 4，检查 4<=3，不成立，循环结束。
s4 | sum=6 | 6 | 循环已经结束，变量 i 也随之失效，最后输出 sum。
```

## 倒序与指定步长

循环并不一定从小数数到大数。倒着数时，把初值设得大一些，条件改成 `>=`，更新写成 `i--`；需要每次跳过几个数时，把更新写成 `i+=2`、`i+=3` 这样的形式。

```cpp frag
for (int i=5;i>=1;i--){
    cout<<i<<" ";
}
cout<<endl;
for (int i=0;i<10;i+=3){
    cout<<i<<" ";
}
cout<<endl;
```

```output
5 4 3 2 1
0 3 6 9
```

## 累加与累乘

循环最常见的用途，是把一系列数据汇总成一个结果。做累加时，要先准备一个初值为 **0** 的变量，每一轮往里加；做累乘时，初值必须是 **1**，如果设成 0，无论乘多少个数结果都是 0。

```cpp frag
int sum=0;
for (int i=1;i<=100;i++){
    sum+=i;
}
cout<<sum<<endl;
int fact=1;
for (int i=1;i<=10;i++){
    fact*=i;
}
cout<<fact<<endl;
```

```output
5050
3628800
```

把循环和上一课的 `if` 结合起来，就可以只累加满足条件的数。下面求 1 到 20 之间所有偶数的和：

```cpp frag
int sum=0;
for (int i=1;i<=20;i++){
    if (i%2==0){
        sum+=i;
    }
}
cout<<sum<<endl;
```

```output
110
```

## 容易出错的地方

首先是循环的次数差一。想让循环体执行 `n` 次，`for (int i=0;i<n;i++)` 和 `for (int i=1;i<=n;i++)` 都是对的，但只要把 `<` 和 `<=` 弄混，就会多执行或少执行一次。写完以后，用 `n=1`、`n=2` 这样很小的数据在脑子里走一遍，是发现这类错误最快的办法。

其次是循环变量的有效范围。在 `for (int i=…)` 里声明的 `i` 只在这个循环内部有效，循环一结束就消失了。如果需要在循环之后继续使用它，就要把变量声明放到 `for` 的外面。

还有一点，不要在循环体内随意修改循环变量，比如在循环体里再写一个 `i++`，会让每一轮实际前进两步。

> [!注意] `for` 括号后面多写了分号
> ```cpp frag
> for (int i=1;i<=3;i++);
> {
>     cout<<"x"<<endl;
> }
> ```
>
> ```output
> x
>```
>
> 这个分号让 `for` 的循环体变成了一条空语句，循环空转了 3 次；后面的花括号于是成了普通的一段代码，只执行一次。编译器对此不会报错，只能靠自己留意。

## 竞赛里的缩写

在比赛里，同样的 `for (int i=1;i<=n;i++)` 要写成百上千次，因此很多人会用宏把它缩短。`#define` 的作用是“把后面的文字原样替换进去”：

```cpp title="rep.cpp"
#include <bits/stdc++.h>
using namespace std;
#define rep(i,l,r) for(int i=l;i<=r;++i)
int main(){
    int sum=0;
    rep(i,1,10){
        sum+=i;
    }
    cout<<sum<<endl;
    return 0;
}
```

```output
55
```

`rep(i,1,10)` 会被替换成 `for(int i=1;i<=10;++i)`，这里的 `++i` 和 `i++` 效果相同。这只是一种偷懒的写法，初学时不必使用，但看到别人这样写时要能认出来。

> [!思考] 用 `for` 输出 10 以内所有 3 的倍数
> 可以用 `i%3==0` 来判断，也可以让 `i` 每次增加 3。

> [!答案] 参考写法
> 使用步长为 3 的写法，循环变量直接跳过非倍数：
>
> ```cpp frag
> for (int i=3;i<=10;i+=3){
>     cout<<i<<" ";
> }
> cout<<endl;
> ```
>
> ```output
> 3 6 9
>```

> [!小结]
> `for` 的括号里依次是初值、条件和更新：初值只在开始时执行一次，每一轮开始前检查条件，每一轮结束后执行更新。累加的变量初值设为 0，累乘的设为 1。倒序用 `i--`，跳着走用 `i+=k`，要小心 `<` 与 `<=` 的取舍，以及括号后面多余的分号。
