# for 循环

> [!目标]
> - 看懂 for 循环的四个部分：初值、条件、更新、循环体
> - 会写正序、倒序、固定步长的循环
> - 会用循环做累加、累乘和“带条件的累加”
> - 认识竞赛里的 `rep` 缩写，也知道几个常见的坑

## 为什么需要循环

想输出 1 到 100，难道要写 100 条 `cout`？**循环**就是让程序把同一段代码重复执行很多次。`for` 是最常用的一种，适合“**已经知道要重复几次**”的场合。

```cpp title="for.cpp"
#include <bits/stdc++.h>
using namespace std;
int main(){
    for (int i=1;i<=5;i++){
        cout<<i<<" ";
    }
    cout<<endl;
    return 0;
}
```

```output
1 2 3 4 5
```

## 四个部分

```cpp noverify
for (初值; 条件; 更新){
    循环体
}
```

以 `for (int i=1;i<=5;i++)` 为例：

| 部分 | 例子 | 什么时候执行 |
| :-- | :-- | :-- |
| ① 初值 | `int i=1` | 循环开始时，**只执行一次** |
| ② 条件 | `i<=5` | **每一轮开始前**检查：成立才进入循环体，不成立就结束 |
| ③ 循环体 | `{ ... }` | 条件成立时执行 |
| ④ 更新 | `i++` | 每次循环体**执行完之后**执行，然后回到②再检查 |

用 1 加到 3 做例子，点播放，盯着 `i` 和 `sum` 看。注意第 2 行（`for` 那一行）会被反复回来检查：

```trace
int sum=0;                       //@s1
for (int i=1;i<=3;i++){          //@s2
    sum=sum+i;                   //@s3
}
cout<<sum;                       //@s4
---
s1 | sum=0 |  | 先准备一个变量 sum，用来累加，初始是 0。
s2 | sum=0; i=1 |  | 进入循环：先执行初值 i=1，再检查条件 1<=3，成立，进入循环体。
s3 | sum=1; i=1 |  | 循环体：sum=sum+i，也就是 0+1，sum 变成 1。
s2 | sum=1; i=2 |  | 循环体做完，执行更新 i++，i 变成 2；再检查 2<=3，成立，再进一轮。
s3 | sum=3; i=2 |  | sum=1+2，变成 3。
s2 | sum=3; i=3 |  | 更新 i 变成 3；检查 3<=3，成立。
s3 | sum=6; i=3 |  | sum=3+3，变成 6。
s2 | sum=6; i=4 |  | 更新 i 变成 4；检查 4<=3，不成立，循环结束。
s4 | sum=6 | 6 | 循环结束，i 也随之消失。输出 sum。
```

## 常见的写法变体

**倒着数**：初值大、条件用 `>=`、更新用 `i--`。**步长不是 1**：更新写成 `i+=2`、`i+=3`。

```cpp frag
for (int i=5;i>=1;i--){
    cout<<i<<" ";
}
cout<<endl;
for (int i=0;i<10;i+=3){
    cout<<i<<" ";
}
cout<<endl;
```

```output
5 4 3 2 1
0 3 6 9
```

## 循环里最常见的两件事：累加和累乘

做累加，先准备一个初值为 **0** 的变量；做累乘，初值要是 **1**（不然乘什么都是 0）。

```cpp frag
int sum=0;
for (int i=1;i<=100;i++){
    sum+=i;
}
cout<<sum<<endl;
int fact=1;
for (int i=1;i<=10;i++){
    fact*=i;
}
cout<<fact<<endl;
```

```output
5050
3628800
```

再配合上一课的 `if`，就能做“带条件的累加”。求 1 到 20 里所有偶数的和：

```cpp frag
int sum=0;
for (int i=1;i<=20;i++){
    if (i%2==0){
        sum+=i;
    }
}
cout<<sum<<endl;
```

```output
110
```

## 容易踩的坑

- **差一个（`<` 和 `<=`）**：想执行 `n` 次，`for (int i=0;i<n;i++)` 和 `for (int i=1;i<=n;i++)` 都对；只写错一个符号，就会多一次或少一次。写完用 `n=1`、`n=2` 的小数据在脑子里走一遍。
- **循环变量只在循环里有效**：在 `for (int i=…)` 里声明的 `i`，出了循环就不存在了。想在循环结束后还用它，就把声明放到 `for` 外面。
- **别在循环体里随便改循环变量**：比如在循环体里写 `i++`，会让循环每次跳两步。

> [!注意] `for` 后面多写了一个分号
> ```cpp frag
> for (int i=1;i<=3;i++);
> {
>     cout<<"x"<<endl;
> }
> ```
>
> ```output
> x
> ```
>
> 分号让 `for` 的循环体成了“空语句”，循环空转了 3 次，后面的 `{ }` 成了普通的一段代码，只执行一次。这类错误编译器不报错，要靠自己留意。

## 竞赛里的缩写：rep

写题时 `for (int i=1;i<=n;i++)` 要写成百上千次，很多人会用一个“宏”把它缩短。`#define` 的意思是“把后面的文字原样替换进去”：

```cpp title="rep.cpp"
#include <bits/stdc++.h>
using namespace std;
#define rep(i,l,r) for(int i=l;i<=r;++i)
int main(){
    int sum=0;
    rep(i,1,10){
        sum+=i;
    }
    cout<<sum<<endl;
    return 0;
}
```

```output
55
```

`rep(i,1,10)` 会被替换成 `for(int i=1;i<=10;++i)`。`++i` 和 `i++` 在这里效果一样。这只是一种偷懒的写法，不会就不用，看到别人这样写时要认得。

> [!思考] 用 for 输出 10 以内所有 3 的倍数
> 提示：用 `i%3==0` 判断，或者让 `i` 每次加 3。

> [!答案] 参考写法
> 步长为 3 的写法：
>
> ```cpp frag
> for (int i=3;i<=10;i+=3){
>     cout<<i<<" ";
> }
> cout<<endl;
> ```
>
> ```output
> 3 6 9
> ```

> [!小结]
> - `for (初值; 条件; 更新)`：初值只做一次，每轮先查条件，循环体后做更新。
> - 累加变量初值 0，累乘变量初值 1。
> - 倒序用 `i--`，跳着走用 `i+=k`；注意 `<` 与 `<=`、别多写分号。
> - `rep` 宏只是缩写，先把完整的 `for` 写顺手。
