# 指针与引用入门

> [!目标]
> - 弄清“变量的地址”是什么，以及指针为什么能保存它
> - 会用 `&` 取地址、用 `*` 通过指针读写变量
> - 理解数组名与指针的关系，分清指针和引用的区别
> - 了解 `new` 和 `delete` 的用法

## 每个变量都有地址

计算机的内存可以想象成一条很长的街道，每个房间都有门牌号。我们声明一个变量，就是租下了一间（或几间）房，变量里的值放在房间里，而这间房的门牌号就叫作这个变量的**地址**。

在变量名前面加上取地址符 `&`，就能得到它的地址。地址本身是一串很长的十六进制数，每次运行都可能不同，所以我们很少去关心它的具体数值，更关心如何通过它找到变量。

## 指针：专门保存地址的变量

**指针**是一种特殊的变量，里面存放的不是普通的数据，而是另一个变量的地址。声明时在类型和名字之间加一个星号：

```cpp title="pointer.cpp"
#include <bits/stdc++.h>
using namespace std;
int main(){
    int a=10;
    int *p=&a;
    cout<<*p<<endl;
    *p=20;
    cout<<a<<endl;
    return 0;
}
```

```output
10
20
```

两个符号的分工要记清楚：

| 写法 | 含义 |
| :-- | :-- |
| `&a` | 取出变量 `a` 的地址 |
| `int *p` | 声明 `p` 是一个“指向 `int` 的指针” |
| `*p` | 顺着 `p` 里的地址找到那个变量本身（称为解引用），既可以读，也可以写 |

下面把这个过程拆开看一遍：

```trace
int a=10;       //@s1
int *p=&a;      //@s2
*p=20;          //@s3
cout<<a;        //@s4
---
s1 | a=10 |  | 变量 a 里保存着 10。
s2 | a=10; p=指向 a |  | p 里存放的是 a 的地址，我们说 p “指向”a。
s3 | a=20; p=指向 a |  | *p 就是 a 本身，给它赋 20，等于直接修改了 a。
s4 | a=20; p=指向 a | 20 | 输出 a，值已经变成了 20。
```

## 指针和数组

数组在内存中是一段连续的空间，而**数组名可以直接当作指向第一个元素的指针**使用。指针加 1，表示移动到下一个元素的位置，所以下面几种写法是等价的：

```cpp frag
int a[4]={10,20,30,40};
int *p=a;
cout<<*p<<" "<<*(p+2)<<" "<<p[3]<<" "<<*(a+1)<<endl;
```

```output
10 30 40 20
```

其实我们平时写的 `a[i]`，编译器就是按 `*(a+i)` 来理解的。前面讲函数传参时，数组传进去之后函数里的修改会影响原数组，原因也在这里：函数拿到的是数组首元素的地址，而不是一份复制品。

## 引用和指针有什么区别

前面介绍过引用，它和指针都能让你间接地访问另一个变量，但使用方式不一样：

| | 引用 | 指针 |
| :-- | :-- | :-- |
| 本质 | 变量的别名 | 保存地址的变量 |
| 声明时 | 必须同时指定绑定的对象 | 可以先不指向任何地方 |
| 能否换对象 | 绑定之后不能再改 | 随时可以指向别的变量 |
| 使用时 | 当普通变量用，写法最简洁 | 需要用 `*` 解引用 |

平时优先用引用，它更简单、更安全。只有在需要“换指向”或者处理链表、树这类用地址连接起来的结构时，才非用指针不可。

## 动态内存：new 与 delete

普通变量和数组的大小在写程序时就定好了。如果想在运行过程中根据需要申请空间，可以用 `new`，用完之后要用 `delete` 归还：

```cpp frag
int *p=new int(5);
cout<<*p<<endl;
delete p;
int n=3;
int *a=new int[n];
for (int i=0;i<n;i++){
    a[i]=i*i;
}
cout<<a[0]<<" "<<a[1]<<" "<<a[2]<<endl;
delete[] a;
```

```output
5
0 1 4
```

申请的是单个对象就用 `delete`，申请的是数组就用 `delete[]`，两者要配对。

> [!竞赛] 比赛里几乎不需要手动 new / delete
> 需要“长度可变的数组”时，用下一部分要学的 `vector` 就行，它会自己管理内存，不会忘记释放。指针更多出现在链表、二叉树这类数据结构里，用来把一个个结点连起来，学到那里再细讲。

> [!注意] 使用指针时的三个常见错误
> 第一，**指针没有指向任何有效的位置就去访问**，比如写了 `int *p;` 之后直接用 `*p`，程序多半会崩溃。第二，访问已经被 `delete` 的内存。第三，数组越界，指针移动得太远。暂时不指向任何东西的指针，应当赋值为 `nullptr`，使用前先判断一下。

> [!小结]
> 指针保存的是变量的地址：`&` 用来取地址，`*` 用来顺着地址找到变量。数组名可以当作首元素的指针，`a[i]` 与 `*(a+i)` 等价。大多数时候用引用就够了，`new` 和 `delete` 现阶段只需要认识。
