# break、continue 与嵌套循环

> [!目标]
> 读完这一课，你应该会用 `break` 提前结束循环，用 `continue` 跳过某一轮，会写循环套循环来打印图形和乘法表，并且能用循环判断一个数是不是素数。

## break：提前结束循环

正常情况下，循环要等到条件不成立才会结束。但有时中途就已经达到了目的，没必要再继续，比如在一堆数里找某个满足条件的数，找到了就可以停了。`break` 的作用就是立刻跳出当前所在的循环，不再理会条件是否还成立。

下面在 1 到 100 之间寻找第一个既是 5 的倍数又是 7 的倍数的数：

```cpp frag
for (int i=1;i<=100;i++){
    if (i%5==0&&i%7==0){
        cout<<i<<endl;
        break;
    }
}
```

```output
35
```

如果去掉 `break`，循环会一直运行到 100，还会把后面的 70 也输出。

## continue：跳过本轮，进入下一轮

`continue` 与 `break` 的区别在于，它不会结束整个循环，只是放弃这一轮循环体里剩下的语句，直接开始下一轮（对 `for` 来说，会先执行更新，再检查条件）。

例如求 1 到 10 中所有奇数之和，可以让遇到偶数的那一轮直接跳过：

```cpp frag
int sum=0;
for (int i=1;i<=10;i++){
    if (i%2==0){
        continue;
    }
    sum+=i;
}
cout<<sum<<endl;
```

```output
25
```

## 嵌套循环

循环的内部还可以再放一个循环，这样的结构叫嵌套循环。可以这样理解：外层循环负责“行”，内层循环负责这一行里的“每一列”。外层每前进一步，内层都要完整地重新执行一遍。

下面打印一个 4 行的三角形，第 `i` 行有 `i` 个星号：

```cpp frag
int n=4;
for (int i=1;i<=n;i++){
    for (int j=1;j<=i;j++){
        cout<<"*";
    }
    cout<<endl;
}
```

```output
*
**
***
****
```

为了看清楚两层循环是怎样配合的，下面把 `n` 取成 2 来走一遍。请注意内层变量 `j` 每次都是重新从 1 开始：

```trace
for (int i=1;i<=2;i++){          //@s1
    for (int j=1;j<=i;j++){      //@s2
        cout<<"*";               //@s3
    }
    cout<<endl;                  //@s4
}
---
s1 | i=1 |  | 外层循环开始，i 等于 1，满足 i<=2，进入循环体。
s2 | i=1; j=1 |  | 内层循环开始，j 等于 1，满足 j<=i，也就是 1<=1。
s3 | i=1; j=1 | * | 输出一个星号。
s2 | i=1; j=2 |  | 内层更新，j 变成 2，检查 2<=1 不成立，这一圈内层循环结束。
s4 | i=1 | \n | 这一行输出完毕，换行。
s1 | i=2 |  | 外层更新，i 变成 2，检查 2<=2 成立，进入下一轮。
s2 | i=2; j=1 |  | 内层循环重新开始，j 又从 1 开始。
s3 | i=2; j=1 | * | 输出一个星号。
s2 | i=2; j=2 |  | j 变成 2，满足 2<=2。
s3 | i=2; j=2 | * | 再输出一个星号。
s2 | i=2; j=3 |  | j 变成 3，检查 3<=2 不成立，内层结束。
s4 | i=2 | \n | 换行。
s1 |  |  | 外层更新，i 变成 3，检查 3<=2 不成立，整个循环结束。
```

再看一个乘法表，`i*j` 正好是第 `i` 行第 `j` 列的数：

```cpp frag
for (int i=1;i<=3;i++){
    for (int j=1;j<=3;j++){
        cout<<i*j<<" ";
    }
    cout<<endl;
}
```

```output
1 2 3
2 4 6
3 6 9
```

> [!注意] 在嵌套循环里，`break` 只能跳出最内层的循环
> ```cpp frag
> for (int i=1;i<=3;i++){
>     for (int j=1;j<=3;j++){
>         if (j==2){
>             break;
>         }
>         cout<<i<<j<<" ";
>     }
> }
> cout<<endl;
> ```
>
> ```output
> 11 21 31
> ```
>
> 每次内层循环遇到 `j==2` 就结束了，但外层循环还在继续。如果想一次跳出多层，可以借助一个标记变量，或者把循环写进函数里用 `return` 退出。

## 综合练习：判断素数

素数是大于 1 的整数，并且除了 1 和它本身之外，不能被其他数整除。判断的思路很直接：依次试一试 2、3、4……能不能整除它，只要有一个能整除，就不是素数。

这里有一个重要的优化。因数总是成对出现的，比如 36=4×9，两个因数一个不超过 6，一个不小于 6，所以只需要试到平方根为止就够了，写成 `i*i<=n`。

```cpp title="prime.cpp"
#include <bits/stdc++.h>
using namespace std;
int main(){
    int n;
    cin>>n;
    bool ok=n>=2;
    for (int i=2;i*i<=n;i++){
        if (n%i==0){
            ok=false;
            break;
        }
    }
    cout<<(ok?"是素数":"不是素数")<<endl;
    return 0;
}
```

```input
17
```

```output
是素数
```

程序里的 `ok` 一开始假设它是素数，一旦发现能整除的数，就把它改成 `false` 并用 `break` 结束，剩下的数不必再试。

> [!竞赛] 为什么写 `i*i<=n` 而不是 `i<=sqrt(n)`
> 两者的含义相同，但前者全程使用整数运算，既避免了小数带来的误差，速度也更快。需要注意的是，当 `n` 很大（比如 10⁹）时，`i*i` 可能超出 `int` 的范围，这时应该把 `i` 声明成 `long long`。

> [!思考] 输出 12 的所有因数
> 提示：从 1 到 12 逐个检查，能整除 12 的就输出。

> [!答案] 参考写法
> ```cpp frag
> int n=12;
> for (int i=1;i<=n;i++){
>     if (n%i==0){
>         cout<<i<<" ";
>     }
> }
> cout<<endl;
> ```
>
> ```output
> 1 2 3 4 6 12
> ```

> [!小结]
> `break` 结束当前循环，`continue` 只跳过当前这一轮。嵌套循环中，外层决定行、内层决定列，外层前进一步，内层完整执行一遍，而 `break` 只会影响最内层。判断素数时，只需要试到 `i*i<=n`，发现因数就可以提前结束。
