# break、continue 与嵌套循环

> [!目标]
> - 会用 `break` 提前结束循环，用 `continue` 跳过本轮
> - 会写“循环套循环”，打印图形、九九乘法表
> - 会用循环判断一个数是不是素数

## break：立刻跳出循环

`break` 的意思是：**不管条件还成不成立，现在就离开这个循环**。常用于“找到了就不用再找了”。

找 1 到 100 里，第一个既是 5 的倍数、又是 7 的倍数的数：

```cpp frag
for (int i=1;i<=100;i++){
    if (i%5==0&&i%7==0){
        cout<<i<<endl;
        break;
    }
}
```

```output
35
```

不写 `break` 的话，程序还会继续找下去，打印出 35 和 70。

## continue：跳过这一轮，进入下一轮

`continue` 的意思是：**这一轮后面的语句不做了，直接开始下一轮**（`for` 会先执行更新部分，再检查条件）。

求 1 到 10 里所有奇数的和（遇到偶数就跳过）：

```cpp frag
int sum=0;
for (int i=1;i<=10;i++){
    if (i%2==0){
        continue;
    }
    sum+=i;
}
cout<<sum<<endl;
```

```output
25
```

## 嵌套循环：循环里面套循环

循环体里可以再放一个循环。可以这样理解：**外层循环管“行”，内层循环管“这一行里的每一列”**。外层转一圈，内层要完整地转一整圈。

打印一个 4 行的三角形：第 `i` 行输出 `i` 个星号。

```cpp frag
int n=4;
for (int i=1;i<=n;i++){
    for (int j=1;j<=i;j++){
        cout<<"*";
    }
    cout<<endl;
}
```

```output
*
**
***
****
```

用 `n=2` 慢慢看一遍，注意第二层循环（`j`）每次都是重新从 1 开始：

```trace
for (int i=1;i<=2;i++){          //@s1
    for (int j=1;j<=i;j++){      //@s2
        cout<<"*";               //@s3
    }
    cout<<endl;                  //@s4
}
---
s1 | i=1 |  | 外层开始：i=1，满足 i<=2，进入。
s2 | i=1; j=1 |  | 内层开始：j=1，满足 j<=i（也就是 1<=1）。
s3 | i=1; j=1 | * | 输出一个星号。
s2 | i=1; j=2 |  | 内层更新 j 变成 2，检查 2<=1 不成立，内层这一圈结束。
s4 | i=1 | \n | 这一行结束，换行。
s1 | i=2 |  | 外层更新：i 变成 2，检查 2<=2，成立，再进一次。
s2 | i=2; j=1 |  | 内层又重新开始，j 从 1 开始。
s3 | i=2; j=1 | * | 输出一个星号。
s2 | i=2; j=2 |  | j 变成 2，2<=2 成立。
s3 | i=2; j=2 | * | 再输出一个星号。
s2 | i=2; j=3 |  | j 变成 3，3<=2 不成立，内层结束。
s4 | i=2 | \n | 换行。
s1 |  |  | 外层更新：i 变成 3，3<=2 不成立，外层结束。
```

再来一个：3×3 的乘法表。`i*j` 就是第 `i` 行第 `j` 列的数。

```cpp frag
for (int i=1;i<=3;i++){
    for (int j=1;j<=3;j++){
        cout<<i*j<<" ";
    }
    cout<<endl;
}
```

```output
1 2 3
2 4 6
3 6 9
```

> [!注意] `break` 只能跳出**最里面**的那一层
> ```cpp frag
> for (int i=1;i<=3;i++){
>     for (int j=1;j<=3;j++){
>         if (j==2){
>             break;
>         }
>         cout<<i<<j<<" ";
>     }
> }
> cout<<endl;
> ```
>
> ```output
> 11 21 31
> ```
>
> 每次内层遇到 `j==2` 就跳出内层，但外层还在继续。想一次跳出两层，可以用一个标记变量，或者把循环放进函数里用 `return`。

## 综合练习：判断素数

**素数**：大于 1，并且除了 1 和它本身，没有别的因数。思路：试着让 2、3、4……去除它，只要有一个能整除，就不是素数。

关键的优化：因数总是成对出现的（比如 36 = 4×9），只需要试到 `√n` 就够了，写成 `i*i<=n`。

```cpp title="prime.cpp"
#include <bits/stdc++.h>
using namespace std;
int main(){
    int n;
    cin>>n;
    bool ok=n>=2;
    for (int i=2;i*i<=n;i++){
        if (n%i==0){
            ok=false;
            break;
        }
    }
    cout<<(ok?"是素数":"不是素数")<<endl;
    return 0;
}
```

```input
17
```

```output
是素数
```

这里 `ok` 一开始假设“是素数”，一旦找到整除的数就改成 `false` 并 `break`，不用再试了。

> [!竞赛] 为什么是 `i*i<=n`，而不是 `i<=sqrt(n)`
> 两者含义一样。用乘法是整数运算，不会碰上 `sqrt` 的小数误差，也更快。注意 `n` 很大时（比如 10⁹），`i*i` 可能超过 `int`，这时把 `i` 声明成 `long long`。

> [!思考] 输出 12 的所有因数
> 提示：从 1 到 12 逐个试，能整除的就输出。

> [!答案] 参考写法
> ```cpp frag
> int n=12;
> for (int i=1;i<=n;i++){
>     if (n%i==0){
>         cout<<i<<" ";
>     }
> }
> cout<<endl;
> ```
>
> ```output
> 1 2 3 4 6 12
> ```

> [!小结]
> - `break`：立刻离开当前循环；`continue`：跳过本轮，直接进入下一轮。
> - 嵌套循环：外层管行、内层管列，外层转一步，内层完整转一圈；`break` 只管最里层。
> - 判断素数：从 2 试到 `i*i<=n`，有一个能整除就不是。
