# 算术运算

> [!目标]
> 读完这一课，你应该能熟练使用加减乘除和取余，清楚整数除法会丢掉小数部分，会用自增、自减和类型转换，并且知道数字太大时会发生溢出以及怎样避免。

## 四则运算与取余

C++ 里的加、减、乘分别用 `+`、`-`、`*` 表示，除法用 `/`，取余数用 `%`。余数运算只能用在整数上。以 `a=7`、`b=2` 为例：

| 运算符 | 含义 | 结果 |
| :-: | :-- | :-: |
| `+` `-` `*` | 加、减、乘 | `a+b` 得 9，`a*b` 得 14 |
| `/` | 除法 | `a/b` 得 **3** |
| `%` | 取余数 | `a%b` 得 1 |

```cpp frag
int a=7,b=2;
cout<<a+b<<" "<<a-b<<" "<<a*b<<" "<<a/b<<" "<<a%b<<endl;
```

```output
9 5 14 3 1
```

留意最后两项：`7/2` 的结果是 3，而不是 3.5。这是下面要专门说明的第一个常见陷阱。

## 整数除法会丢掉小数部分

当除号两边**都是整数**时，C++ 做的是整数除法，结果也是整数，小数部分被直接舍去，而不是四舍五入。要得到带小数的结果，至少要让其中一个数是小数：

```cpp frag
int a=7,b=2;
cout<<a/b<<endl;
cout<<7.0/2<<endl;
cout<<(double)a/b<<endl;
cout<<1.0*a/b<<endl;
```

```output
3
3.5
3.5
3.5
```

`(double)a` 表示把 `a` 临时当作小数使用，这叫强制类型转换。另一个常见的小技巧是乘上 `1.0`：只要算式中出现了小数，整个运算就按小数来进行。

> [!注意] 事后再换成 `double` 来不及
> 下面这段程序把 `7/2` 的结果存进了 `double` 变量，可是除法在存入之前就已经按整数算完了：
>
> ```cpp frag
> double x=7/2;
> cout<<x<<endl;
> ```
>
> ```output
> 3
> ```
>
> 正确的写法是 `double x=7.0/2;`。

## 取余运算的用途

取余运算看上去简单，却是算法竞赛里使用频率最高的运算之一。下面是几种典型的用法：

| 想做的事 | 写法（`n` 为整数） |
| :-- | :-- |
| 判断偶数、奇数 | `n%2==0`、`n%2!=0` |
| 判断能否被 `k` 整除 | `n%k==0` |
| 取出个位数字 | `n%10` |
| 去掉个位数字 | `n/10` |
| 让数值在固定范围内循环（例如 0 到 6） | `i%7` |

比如要把一个三位数的百位、十位、个位分别取出来，可以这样做：

```cpp frag
int n=358;
cout<<n/100<<" "<<n/10%10<<" "<<n%10<<endl;
```

```output
3 5 8
```

> [!提示] 负数取余，符号跟着左边的数
> 当被除数是负数时，余数也是负数：
>
> ```cpp frag
> cout<<-7%3<<" "<<7%-3<<endl;
> ```
>
> ```output
> -1 1
> ```
>
> 因此判断奇数最好写成 `n%2!=0`，而不是 `n%2==1`，否则遇到 `-3` 这样的负奇数就会判断错。

## 自增、自减与复合赋值

`i++` 的作用是让 `i` 增加 1，`i--` 让 `i` 减少 1。`a+=3` 是 `a=a+3` 的简写，`-=`、`*=`、`/=`、`%=` 也是同样的道理。

自增符号放在变量前面还是后面，在单独成句时没有区别；一旦它和别的运算写在同一条语句里，区别就出现了。**后置**的 `a++` 先使用 `a` 当前的值，然后才加 1；**前置**的 `++a` 则先加 1，再使用新的值。

```trace
int a=5;                    //@s1
int b=a++;                  //@s2
int c=++a;                  //@s3
cout<<a<<" "<<b<<" "<<c;    //@s4
---
s1 | a=5 |  | 变量 a 的初值是 5。
s2 | a=6; b=5 |  | 后置的 a++ 先把 a 当前的值 5 交给 b，然后 a 才增加 1，变成 6。
s3 | a=7; b=5; c=7 |  | 前置的 ++a 先让 a 增加 1，变成 7，再把这个新值交给 c。
s4 | a=7; b=5; c=7 | 7 5 7 | 输出三个变量此刻的值。
```

初学阶段，建议让 `++` 和 `--` 单独占一条语句，不要和其他运算混写，这样不容易出错。

## 类型转换与取整

不同类型的数据一起运算时，C++ 会把“范围小的”自动提升为“范围大的”，所以 `int` 和 `double` 相加，结果是 `double`。反过来，把小数赋给整型变量，小数部分会被直接舍去，并不会四舍五入。

需要取整时，有几个现成的函数，它们的区别如下：

```cpp frag
cout<<(int)3.9<<" "<<round(3.5)<<" "<<ceil(3.1)<<" "<<floor(3.9)<<endl;
```

```output
3 4 4 3
```

`(int)3.9` 直接舍去小数，得到 3；`round` 是四舍五入；`ceil` 向上取整；`floor` 向下取整。

> [!竞赛] 整数的向上取整不必用 `ceil`
> 如果要计算“`a` 个物品，每 `b` 个装一组，至少需要几组”，也就是 `a` 除以 `b` 向上取整，更稳妥的写法是 `(a+b-1)/b`。例如 `(7+2-1)/2` 的结果是 4。它全程都是整数运算，不会引入小数的误差。

## 溢出：数值超出了类型能表示的范围

`int` 能表示的最大值约为 21 亿。如果运算的结果超出了这个范围，数值就会“绕一圈”，变成一个看上去毫无道理的数，而且程序不会给出任何提示。

```cpp frag
int a=100000,b=100000;
cout<<a*b<<endl;
cout<<(long long)a*b<<endl;
```

```output
1410065408
10000000000
```

第一行本应是 100 亿，却输出了 1410065408。第二行先把 `a` 转换成 `long long` 再相乘，结果就是正确的。

还有一种更隐蔽的情况，变量是 `long long`，结果仍然是错的：

```cpp frag
long long x=100000*100000;
long long y=100000LL*100000;
cout<<x<<" "<<y<<endl;
```

```output
1410065408 10000000000
```

等号右边的 `100000*100000` 是两个 `int` 相乘，乘法在这里就已经溢出了，之后再存进 `long long` 为时已晚。只要给其中一个数加上后缀 `LL`，或者提前转换类型，让乘法在 `long long` 范围内进行，就能避免这个问题。

> [!竞赛] 看到乘法和累加，先想想会不会溢出
> 只要有一点担心，就把相关的变量全部声明为 `long long`，输出时对应用 `%lld`。算法竞赛里“思路正确，却只得了部分分”，常常就是溢出造成的。

## 常用的数学函数

`sqrt`、`pow` 这些数学函数定义在 `<cmath>` 里，而 `bits/stdc++.h` 已经全部包含了它们。

```cpp frag
cout<<sqrt(16)<<" "<<pow(2,10)<<" "<<abs(-5)<<" "<<fabs(-2.5)<<" "<<max(3,8)<<" "<<min(3,8)<<endl;
```

```output
4 1024 5 2.5 8 3
```

> [!注意] `pow` 的返回值是小数
> `pow` 算出来的是 `double`，有时会带有极小的误差。如果要计算整数的乘方，比赛中常见的做法是用循环连乘，或者用位运算 `1<<k` 表示 2 的 k 次方，这样更稳妥。

## 练习

> [!思考] 输入一个三位数，求它各位数字之和
> 比如 358 的各位数字之和是 3+5+8=16。试着用刚才学到的运算完成它。

> [!答案] 参考写法
> 把百位、十位和个位分别取出来再相加：
>
> ```cpp frag
> int n=358;
> cout<<n/100+n/10%10+n%10<<endl;
> ```
>
> ```output
> 16
> ```

> [!小结]
> 两个整数相除得到整数，小数部分被舍去，需要小数时让其中一个变成 `double`。取余运算可以用来判断整除、拆分数位。`a++` 与 `++a` 的区别只在于“先用后加”还是“先加后用”。当运算结果可能超出 `int` 的范围时，要改用 `long long`，并且在乘法发生之前就完成转换。
