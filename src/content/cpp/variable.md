# 变量与数据类型

> [!目标]
> 读完这一课，你应该理解变量是如何保存数据的，能够声明和修改变量，并且知道 `int`、`long long`、`double`、`char`、`bool` 各自适合存放什么。

## 变量是什么

程序要处理数据，就得先把数据存起来，供后面反复使用。**变量**就是用来存放数据的一小块内存：我们给它起一个名字，方便以后用这个名字来读取或修改里面的值；同时规定它的类型，说明里面能放哪一类数据。把它想象成一只贴了标签的盒子会很直观：标签是名字，盒子里的东西是值，盒子的规格决定了能装什么。

```cpp title="variable.cpp"
#include <bits/stdc++.h>
using namespace std;
int main(){
    int age=18;
    double height=1.75;
    char grade='A';
    bool pass=true;
    cout<<age<<" "<<height<<" "<<grade<<" "<<pass<<endl;
    return 0;
}
```

```output
18 1.75 A 1
```

声明变量的格式是固定的，先写类型，再写名字，最后可以用等号给一个初始值：

```text
类型 名字 = 初始值;
```

所以 `int age=18;` 的意思是：准备一个可以存放整数的变量，取名为 `age`，并让它一开始就等于 18。

## 常用的数据类型

C++ 把数据分成不同的类型，是因为不同的数据占用的空间不一样，处理的方式也不一样。入门阶段需要熟悉下面几种：

| 类型 | 存放的内容 | 范围或大小 | 例子 |
| :-- | :-- | :-- | :-- |
| `int` | 整数 | 约正负 21 亿（−2147483648 到 2147483647），占 4 字节 | `18`、`-5` |
| `long long` | 范围更大的整数 | 约正负 9.2×10¹⁸，占 8 字节 | `10000000000` |
| `double` | 小数 | 占 8 字节，约 15 位有效数字 | `3.14` |
| `char` | 单个字符 | 占 1 字节，写在**单引号**里 | `'A'` |
| `bool` | 真或假 | `true` 输出为 1，`false` 输出为 0 | `true` |
| `string` | 一段文字 | 长度可变 | `"hello"`（之后会专门讲） |

想知道各个类型在你的环境里占多少字节，可以用 `sizeof` 查看：

```cpp frag
cout<<sizeof(int)<<" "<<sizeof(long long)<<" "<<sizeof(double)<<" "<<sizeof(char)<<" "<<sizeof(bool)<<endl;
```

```output
4 8 8 1 1
```

> [!竞赛] 拿不准的时候，选 `long long`
> `int` 最大只有约 21 亿。题目的数据范围一旦达到 10⁹ 以上，或者需要把两个较大的数相乘、把很多数累加，就应该使用 `long long`，否则结果会在不知不觉中溢出。下一课讲算术运算时，会亲眼看到这种情况是怎么发生的。

## 赋值

`=` 在这里和数学里的“等于”并不是一回事，它的含义是**先计算右边，再把结果放进左边的变量**，变量里原来的值会被覆盖。下面的演示展示了 `a` 和 `b` 是怎样一步步改变的：

```trace
int a=3;            //@s1
int b=a+4;          //@s2
a=10;               //@s3
b=a*2;              //@s4
cout<<a<<" "<<b;    //@s5
---
s1 | a=3 |  | 创建变量 a，并把 3 放进去。
s2 | a=3; b=7 |  | 先计算右边的 a+4，得到 7，再创建变量 b 并存入 7。
s3 | a=10; b=7 |  | 把 10 存进 a，原来的 3 被覆盖；b 没有受到影响，仍然是 7。
s4 | a=10; b=20 |  | 先算出右边的 a*2，得到 20，存进 b，原来的 7 被覆盖。
s5 | a=10; b=20 | 10 20 | 输出此刻 a 和 b 的值。
```

编程里常见 `a=a+1` 这样的写法，它不是在宣称一个不可能成立的等式，而是“取出 a 现在的值，加 1，再放回 a”。

## 变量的命名

名字可以自己取，但要遵守几条规则：只能由字母、数字和下划线组成，不能以数字开头，所以 `score1` 可以而 `1score` 不行；区分大小写，`Age` 和 `age` 是两个不同的变量；不能使用 `int`、`for`、`return` 这类 C++ 已经占用的关键字。

在这些规则之内，最好让名字说明它的用途，比如 `score` 表示成绩，`sum` 表示总和。算法竞赛里还有一些约定俗成的短名字，也需要认识：`n` 通常表示数据的个数，`i` 和 `j` 用作循环变量，`ans` 表示答案，`cnt` 表示计数。

同一种类型的变量可以放在一条语句里一起声明：

```cpp frag
int a=1,b=2,c;
c=a+b;
cout<<c<<endl;
```

```output
3
```

## 用 const 声明不变的量

有些值在整个程序里都不应该改变，比如圆周率。在声明前加上 `const`，如果后面不小心修改了它，编译器会直接报错，这样既防止了失误，也让阅读的人明白它是个常量。

```cpp frag
const double PI=3.14159;
double r=2;
cout<<PI*r*r<<endl;
```

```output
12.5664
```

> [!注意] 声明变量时应当同时赋初值
> 在函数里声明变量却不给初值，它里面存放的是一个不确定的值，取决于那块内存之前被用来做过什么：
>
> ```cpp noverify
> int x;
> cout<<x;   // 输出什么都有可能
> ```
>
> 所以养成习惯，声明的同时就赋值，比如 `int sum=0;`。

> [!思考] 下面四个名字中，哪些不能用作变量名？`2nd`、`my_score`、`float`、`Total`

> [!答案] 参考答案
> `2nd` 以数字开头，`float` 是 C++ 的关键字，这两个不合法；`my_score` 和 `Total` 都是合法的。

> [!小结]
> 变量由类型、名字和值三部分组成，声明的格式是“类型 名字 = 初始值”。整数用 `int`，范围不够就换成 `long long`；小数用 `double`；单个字符用 `char`，要用单引号；真假用 `bool`。赋值总是先算右边、再存入左边，不会改变的量可以用 `const` 保护起来。
