# 变量与数据类型

> [!目标]
> - 理解“变量就是带标签的盒子”
> - 会声明变量、赋值，认识 `int`、`long long`、`double`、`char`、`bool`
> - 知道什么时候该用 `long long`
> - 会给变量起名字，会用 `const` 定义不变的值

## 变量：带标签的盒子

程序要处理数据，就得先把数据存起来。**变量**就像一个贴了标签的盒子：标签是它的**名字**，盒子里装的是它的**值**，盒子能装什么，由它的**类型**决定。

```cpp title="variable.cpp"
#include <bits/stdc++.h>
using namespace std;
int main(){
    int age=18;
    double height=1.75;
    char grade='A';
    bool pass=true;
    cout<<age<<" "<<height<<" "<<grade<<" "<<pass<<endl;
    return 0;
}
```

```output
18 1.75 A 1
```

声明一个变量的格式永远是：

```text
类型 名字 = 初始值;
```

比如 `int age=18;`：造一个能装整数的盒子，贴上标签 `age`，里面先放 `18`。

## 常用的数据类型

| 类型 | 装什么 | 范围 / 大小 | 例子 |
| :-- | :-- | :-- | :-- |
| `int` | 整数 | 约 −21 亿 ~ 21 亿（−2147483648 ~ 2147483647），4 字节 | `18`、`-5` |
| `long long` | 大整数 | 约 ±9.2×10¹⁸，8 字节 | `10000000000` |
| `double` | 小数 | 8 字节，约 15 位有效数字 | `3.14` |
| `char` | **单个**字符 | 1 字节，用**单引号** | `'A'` |
| `bool` | 真 / 假 | `true`（输出 1）、`false`（输出 0） | `true` |
| `string` | 一串文字 | 随长度 | `"hello"`（后面专门讲） |

想亲眼看看各类型占多少字节，可以用 `sizeof`：

```cpp frag
cout<<sizeof(int)<<" "<<sizeof(long long)<<" "<<sizeof(double)<<" "<<sizeof(char)<<" "<<sizeof(bool)<<endl;
```

```output
4 8 8 1 1
```

> [!竞赛] 拿不准就用 `long long`
> `int` 最大只有约 21 亿。题目里只要出现“数据范围到 10⁹ 以上”，或者要把两个大数**相乘 / 累加**，就用 `long long`，不然会悄悄溢出，答案错得莫名其妙。下一章讲算术运算时会亲眼看到。

## 赋值：把值放进盒子

`=` 在这里**不是数学里的“等于”**，而是“**把右边的结果，放进左边的盒子**”。盒子里原来的东西会被盖掉。

点播放，注意看变量 `a`、`b` 是怎么一步步变化的：

```trace
int a=3;            //@s1
int b=a+4;          //@s2
a=10;               //@s3
b=a*2;              //@s4
cout<<a<<" "<<b;    //@s5
---
s1 | a=3 |  | 造了一个盒子 a，里面放 3。
s2 | a=3; b=7 |  | 先算右边：a+4 = 7，再造盒子 b，把 7 放进去。
s3 | a=10; b=7 |  | 把 10 放进 a。原来的 3 被盖掉了；b 不受影响，还是 7。
s4 | a=10; b=20 |  | 先算右边：a*2 = 20，放进 b，原来的 7 被盖掉。
s5 | a=10; b=20 | 10 20 | 输出 a 和 b 当前的值。
```

常见的写法 `a=a+1`，读作“把 a 现在的值加 1，再放回 a”，不是数学里不可能成立的等式。

## 给变量起名字

- 只能用**字母、数字、下划线**，而且**不能以数字开头**：`score1` 可以，`1score` 不行。
- **区分大小写**：`Age` 和 `age` 是两个不同的变量。
- 不能用 C++ 已经占用的词（关键字），比如 `int`、`for`、`return`。
- 名字最好能看出用途：`score`（成绩）、`sum`（总和）。竞赛里常见的短名字也要认识：`n`（个数）、`i`、`j`（循环用）、`ans`（答案）、`cnt`（计数）。

同类型的变量可以一次声明多个：

```cpp frag
int a=1,b=2,c;
c=a+b;
cout<<c<<endl;
```

```output
3
```

## 常量：不许改的值

有些值整个程序里都不该变（比如圆周率），可以加上 `const`，万一不小心改它，编译器会直接报错提醒你：

```cpp frag
const double PI=3.14159;
double r=2;
cout<<PI*r*r<<endl;
```

```output
12.5664
```

> [!注意] 不赋初值的变量里是“垃圾”
> 在函数里声明变量却不给初值，盒子里装的是上一个程序留下的不确定的东西：
>
> ```cpp noverify
> int x;
> cout<<x;   // 输出什么都有可能
> ```
>
> 养成习惯：**声明的同时就赋初值**，比如 `int sum=0;`。

> [!思考] 想一想
> 下面这几个名字，哪些不合法？`2nd`、`my_score`、`float`、`Total`

> [!答案] 参考答案
> `2nd` 以数字开头、`float` 是关键字，这两个不合法；`my_score` 和 `Total` 是合法的。

> [!小结]
> - 变量 = 带标签的盒子，声明格式：`类型 名字=初始值;`
> - 整数用 `int`，装不下就换 `long long`；小数用 `double`；单个字符用 `char`（单引号）；真假用 `bool`。
> - `=` 是赋值：先算右边，再放进左边。
> - 声明时就赋初值；不变的值用 `const`。
