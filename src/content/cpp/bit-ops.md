# 位运算

> [!目标]
> - 理解整数在计算机里的二进制表示，认识 `&`、`|`、`^`、`~`、`<<`、`>>` 六个运算符
> - 掌握取出、设置、清除某一位，`lowbit`，判断 2 的幂，统计二进制中 1 的个数等常用技巧
> - 理解异或的性质，会用它找出只出现一次的数，会用位掩码枚举子集，会写快速幂

## 二进制与六个运算符

计算机用二进制保存整数，每一位只有 0 和 1。位运算就是直接对这些二进制位做操作。以 12（二进制 `1100`）和 10（二进制 `1010`）为例：

| 运算符 | 含义 | 12 与 10 的结果 |
| :-: | :-- | :-- |
| `a&b` | 按位与：两位都是 1 才是 1 | `1000`，即 8 |
| `a\|b` | 按位或：有一位是 1 就是 1 | `1110`，即 14 |
| `a^b` | 按位异或：两位不同才是 1 | `0110`，即 6 |
| `~a` | 按位取反：0 变 1，1 变 0 | -13 |
| `a<<k` | 左移 k 位，相当于乘以 2 的 k 次方 | 12<<2 是 48 |
| `a>>k` | 右移 k 位，相当于除以 2 的 k 次方（向下取整） | 12>>2 是 3 |

```cpp title="bit_basic.cpp"
#include <bits/stdc++.h>
using namespace std;
int main(){
    int a=12,b=10;
    cout<<(a&b)<<" "<<(a|b)<<" "<<(a^b)<<" "<<(~a)<<endl;
    cout<<(a<<2)<<" "<<(a>>2)<<endl;
    cout<<bitset<8>(a)<<" "<<bitset<8>(b)<<endl;
    return 0;
}
```

```output
8 14 6 -13
48 3
00001100 00001010
```

`bitset<8>(a)` 可以把一个整数按 8 位二进制输出，调试位运算时非常有用。

> [!注意] 位运算的优先级低于比较运算：`a&b==c` 会被解释成 `a&(b==c)`，与想要的意思不同。凡是混用，一律加括号，写成 `(a&b)==c`。

## 常用的位技巧

下面这些写法几乎每道位运算题都会用到。其中 `1<<k` 表示只有第 k 位（从 0 开始，从右数）是 1 的数，用它可以对第 k 位做各种操作。

```cpp title="bit_tricks.cpp"
#include <bits/stdc++.h>
using namespace std;
int main(){
    int n=22;
    cout<<bitset<8>(n)<<endl;
    cout<<"是奇数吗："<<(n&1)<<endl;
    cout<<"第 1 位："<<((n>>1)&1)<<"，第 3 位："<<((n>>3)&1)<<endl;
    cout<<"第 3 位置 1："<<bitset<8>(n|(1<<3))<<endl;
    cout<<"第 1 位清 0："<<bitset<8>(n&~(1<<1))<<endl;
    cout<<"第 2 位翻转："<<bitset<8>(n^(1<<2))<<endl;
    cout<<"lowbit："<<(n&-n)<<endl;
    cout<<"清掉最低位的 1："<<bitset<8>(n&(n-1))<<endl;
    int p=64;
    cout<<"64 是 2 的幂吗："<<(p>0&&(p&(p-1))==0)<<endl;
    cout<<"1 的个数："<<__builtin_popcount(n)<<endl;
    return 0;
}
```

```output
00010110
是奇数吗：0
第 1 位：1，第 3 位：0
第 3 位置 1：00011110
第 1 位清 0：00010100
第 2 位翻转：00010010
lowbit：2
清掉最低位的 1：00010100
64 是 2 的幂吗：1
1 的个数：3
```

几个技巧的道理值得弄明白。`n&1` 取出最低位，所以能判断奇偶。`n&-n` 只保留最低位的 1，叫作 `lowbit`，树状数组会用到它。`n&(n-1)` 的作用是把最低位的 1 变成 0：减一时，最低位的 1 变成 0，它右边的 0 全部变成 1，与原来的数按位与之后，这些位就都抵消了。

由此可以得到两个推论：2 的幂的二进制里只有一个 1，所以 `n&(n-1)` 之后恰好是 0，这就是判断 2 的幂的方法（还要保证 `n>0`）；反复地执行 `n&=n-1`，每次消掉一个 1，执行的次数就是二进制里 1 的个数，这个数叫作汉明重量。GCC 提供了 `__builtin_popcount`，直接就能求出，`long long` 对应的版本是 `__builtin_popcountll`。

> [!注意] `1<<k` 的类型是 `int`，当 `k` 达到 31 时会溢出。处理 `long long` 时要写成 `1LL<<k`。

## 异或的性质

异或有几条很有用的性质：`a^a=0`（自己和自己异或得 0），`a^0=a`（和 0 异或不变），以及它满足交换律和结合律。把它们组合起来，就可以得到一些巧妙的结论。

如果一个数组里，除了一个数以外，其他的数都出现了两次，把全部数异或起来，成对的数相互抵消，剩下的就是那个只出现一次的数。进一步，如果有**两个**数出现了奇数次，其余都成对出现，做法是：全部异或，得到这两个数的异或值 `x`；`x` 一定不为 0，取它的最低位的 1，这一位上两个数一个是 0、一个是 1；按这一位把所有数分成两组，每组各含其中一个数，再各自异或，就分别得到了它们。

```cpp title="xor_find.cpp"
#include <bits/stdc++.h>
using namespace std;
int main(){
    int arr[]={1,2,3,2,3,4,1,5};
    int n=sizeof(arr)/sizeof(arr[0]);
    int x=0;
    for (int i=0;i<n;i++){
        x^=arr[i];
    }
    int mask=x&-x;
    int a=0,b=0;
    for (int i=0;i<n;i++){
        if (arr[i]&mask) a^=arr[i];
        else b^=arr[i];
    }
    cout<<min(a,b)<<" "<<max(a,b)<<endl;
    return 0;
}
```

```output
4 5
```

数组里 1、2、3 各出现两次，4 和 5 各出现一次，程序找出了这两个数。只用一遍扫描和常数个变量，不需要排序，也不需要 `map`。

交换两个变量用 `^` 也能完成（`a^=b; b^=a; a^=b;`），但它没有任何速度上的好处，而且当两个变量是同一个变量时会变成 0，所以平时直接使用 `swap` 即可，了解它是为了读懂别人的代码。

## 位掩码与子集枚举

一个 n 位的二进制数，可以表示“n 个元素里选了哪些”：第 i 位为 1 表示选了第 i 个元素。从 0 到 `(1<<n)-1` 的所有整数，正好对应所有 `2^n` 个子集。

```cpp title="subsets.cpp"
#include <bits/stdc++.h>
using namespace std;
int main(){
    string items="abc";
    int n=items.size();
    for (int mask=0;mask<(1<<n);mask++){
        string sub;
        for (int i=0;i<n;i++){
            if (mask>>i&1) sub+=items[i];
        }
        cout<<bitset<3>(mask)<<" {"<<sub<<"}"<<endl;
    }
    return 0;
}
```

```output
000 {}
001 {a}
010 {b}
011 {ab}
100 {c}
101 {ac}
110 {bc}
111 {abc}
```

这个办法在 n 不大（二十以内）的时候，是枚举所有子集的最简洁的写法，状态压缩的动态规划就建立在它的基础之上。

## 快速幂

计算 a 的 n 次方，如果一个一个地乘，要乘 n 次。快速幂利用了 n 的二进制：比如 13 的二进制是 `1101`，所以 `a^13=a^8·a^4·a^1`。从低位到高位依次处理 n 的每一位，同时让底数不断平方（`a`、`a²`、`a⁴`、`a⁸`……），遇到 1 的那一位，就把当前的底数乘进结果。这样只需要大约 `log n` 次乘法。

```cpp title="quick_pow.cpp"
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
ll quickPow(ll a,ll n,ll mod){
    ll res=1;
    a%=mod;
    while (n>0){
        if (n&1) res=res*a%mod;
        a=a*a%mod;
        n>>=1;
    }
    return res;
}
int main(){
    cout<<quickPow(3,13,1000000007)<<endl;
    cout<<quickPow(2,100,1000000007)<<endl;
    return 0;
}
```

```output
1594323
976371285
```

`n&1` 判断当前最低位是不是 1，`n>>=1` 把已经处理过的最低位丢掉。每一步都取模，避免数字太大溢出。写法上最容易出错的，是把 `n&1` 写成 `n&=1`，或者漏了 `n>>=1`，这样 `n` 永远不会变小，循环无法结束。

> [!竞赛] 位运算在比赛里的主要用途有：状态压缩（用一个整数表示一个集合）、树状数组（`lowbit`）、异或的各种性质、快速幂与大数运算中的取模。位运算的速度也比乘除法略快，但编译器通常会自动优化，不必为速度刻意改写。

> [!思考] 为什么 `n&(n-1)` 可以把最低位的 1 消掉？

> [!答案] 参考思路
> 设 n 的最低位的 1 在第 k 位，那么 n-1 会让第 k 位变成 0，第 k 位右边原本全是 0 的位全部变成 1，而第 k 位左边的位保持不变。与 n 按位与之后，第 k 位及其右边都是 0，左边不变，所以刚好消掉了最低位的 1。

> [!小结]
> 位运算直接操作二进制位：`&` 取出，`|` 置位，`^` 翻转，`<<`、`>>` 乘除 2 的幂。`n&-n` 是 lowbit，`n&(n-1)` 消掉最低位的 1，由它可得判断 2 的幂和统计 1 的个数。异或相同的数得 0，可用来找出只出现一次的数。位掩码用整数的每一位表示一个元素的选择，快速幂把指数按二进制拆开。
