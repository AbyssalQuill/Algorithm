# 一维数组

> [!目标]
> 读完这一课，你应该理解数组是一排连续的存储单元、下标从 0 开始，会声明、赋值、读入和遍历数组，会用数组找最大值和计数，并且知道越界的危险和全局数组的写法。

## 为什么需要数组

假设要保存 5 位同学的成绩。用前面学过的知识，可以声明五个变量；可是如果有一百位同学呢，总不能写一百个变量名。**数组**解决的就是这个问题：它把相同类型的一批数据放在一排连续的存储单元里，共用同一个名字，再用编号区分其中的每一个，这个编号叫作**下标**。

```cpp frag
int a[5]={10,20,30,40,50};
cout<<a[0]<<" "<<a[4]<<endl;
a[2]=99;
cout<<a[2]<<endl;
```

```output
10 50
99
```

| 下标 | 0 | 1 | 2 | 3 | 4 |
| :-: | :-: | :-: | :-: | :-: | :-: |
| 值 | 10 | 20 | 30 | 40 | 50 |

`int a[5]` 表示声明一个能放 5 个整数的数组，取名为 `a`。**下标是从 0 开始的**，所以这 5 个元素的下标依次为 0 到 4，并不存在 `a[5]`。这一点和日常的数数习惯不同，需要尽早适应。

## 给数组赋初值

声明数组的同时，可以用花括号一次性给出前面几个元素的值：

```cpp frag
int a[5]={1,2,3};
for (int i=0;i<5;i++){
    cout<<a[i]<<" ";
}
cout<<endl;
```

```output
1 2 3 0 0
```

给出了几个，就从前往后依次放入几个，没有给出的部分会自动补成 0。因此 `int a[100]={0};` 是把整个数组清零的常见写法。

## 读入、遍历与输出

处理数组的基本方式，是用 `for` 循环让下标从 0 走到 `n-1`。下面的程序先读入 `n` 个数，再倒着输出：

```cpp title="reverse.cpp"
#include <bits/stdc++.h>
using namespace std;
int main(){
    int n;
    int a[105];
    cin>>n;
    for (int i=0;i<n;i++){
        cin>>a[i];
    }
    for (int i=n-1;i>=0;i--){
        cout<<a[i]<<" ";
    }
    cout<<endl;
    return 0;
}
```

```input
5
1 2 3 4 5
```

```output
5 4 3 2 1
```

## 找最大值

找最大值的常见做法叫“打擂台”：先让第一个数当擂主，然后让其余的数依次上台挑战，谁更大，谁就成为新的擂主。全部挑战完，剩下的擂主就是最大值。

```trace
int a[3]={5,2,8};                 //@s1
int mx=a[0];                      //@s2
for (int i=1;i<3;i++){            //@s3
    if (a[i]>mx){                 //@s4
        mx=a[i];                  //@s5
    }
}
cout<<mx;                         //@s6
---
s1 | a=[5,2,8] |  | 数组里有三个数。
s2 | a=[5,2,8]; mx=5 |  | 先让第一个数 a[0] 当擂主，mx 记录为 5。
s3 | a=[5,2,8]; mx=5; i=1 |  | 从第二个数开始挑战。
s4 | a=[5,2,8]; mx=5; i=1 |  | a[1] 是 2，2>5 不成立，擂主不变。
s3 | a=[5,2,8]; mx=5; i=2 |  | 轮到下一个挑战者。
s4 | a=[5,2,8]; mx=5; i=2 |  | a[2] 是 8，8>5 成立。
s5 | a=[5,2,8]; mx=8; i=2 |  | 8 获胜，成为新的擂主，mx 更新为 8。
s3 | a=[5,2,8]; mx=8; i=3 |  | i 变成 3，3<3 不成立，挑战结束。
s6 | a=[5,2,8]; mx=8 | 8 | 输出最大值。
```

找最小值只需把比较方向反过来；求和与求平均值，则是在遍历的同时进行累加。

## 用数组计数

要统计某个数出现了几次，有一个很巧妙的办法：让“数本身”充当数组的下标，用一个计数数组记录每个数出现的次数。这种数组常被称为“桶”。

```cpp title="count.cpp"
#include <bits/stdc++.h>
using namespace std;
int cnt[105];
int main(){
    int n,x;
    cin>>n;
    for (int i=0;i<n;i++){
        cin>>x;
        cnt[x]++;
    }
    for (int v=1;v<=3;v++){
        cout<<v<<" 出现了 "<<cnt[v]<<" 次"<<endl;
    }
    return 0;
}
```

```input
6
1 3 1 2 3 1
```

```output
1 出现了 3 次
2 出现了 1 次
3 出现了 2 次
```

`cnt[x]++` 的意思是找到下标为 `x` 的那个单元，让里面的数加 1。输入一个 1，`cnt[1]` 就增加一次。

## 全局数组

细心的话会发现，上面的 `cnt` 声明在 `main` 的外面，这样的变量叫全局变量。数组放在全局有两个好处。第一，全局变量一开始自动全是 0，不需要手动清零。第二，空间更充足：函数内部声明的变量放在一块较小的区域（栈）里，数组开得太大会让程序直接崩溃，而全局变量放在另一块大得多的区域，开几百万个 `int` 也没有问题。

所以比赛里的标准写法是：

```cpp noverify
const int N=100005;     // 比题目的数据范围多开几个
int a[N];               // 全局数组，自动全是 0
```

> [!竞赛] 数组要比数据范围多开几个
> 题目说 `n≤100000`，就开成 `100005` 或者 `100010`。多开几个，几乎不占额外的内存；而少开了哪怕一个，就可能越界，导致答案错误或者程序崩溃。

## 清零与填充

```cpp frag
int a[5];
fill(a,a+5,7);
memset(a+1,0,sizeof(int)*2);
for (int i=0;i<5;i++){
    cout<<a[i]<<" ";
}
cout<<endl;
```

```output
7 0 0 7 7
```

`fill(a,a+n,v)` 把前 `n` 个元素都设成 `v`。`memset(a,0,sizeof(a))` 用来把整个数组清零，它是按字节来填充的，因此只适合填 0 或者 -1，不要拿它去填 1 之类的其他值。`sizeof(a)/sizeof(a[0])` 则可以算出数组一共有多少个元素。

## 数组越界

如果访问的下标超出了数组的范围，比如对只有 5 个元素的数组去读 `a[5]` 或 `a[-1]`，这就叫越界。C++ 不会替你检查，也不会报错，程序可能照常运行，也可能莫名其妙地崩溃，甚至悄悄改坏旁边其他变量的值。

```cpp noverify
int a[5]={1,2,3,4,5};
cout<<a[5];     // 越界！a 只有 a[0] 到 a[4]
```

当程序在自己电脑上运行正常，提交之后却答案错误或者运行出错时，首先要检查的就是有没有数组越界。

> [!思考] 求 3、5、8、4、10 这五个数的平均数
> 把它们放进数组，遍历求和，再除以个数。

> [!答案] 参考写法
> ```cpp frag
> int a[5]={3,5,8,4,10};
> int sum=0;
> for (int i=0;i<5;i++){
>     sum+=a[i];
> }
> cout<<sum/5<<endl;
> ```
>
> ```output
> 6
> ```
>
> 这里的平均数恰好是整数。如果可能出现小数，要把除法改成 `1.0*sum/5`，否则小数部分会被舍去。

> [!小结]
> 数组是一排连续的、共用名字的存储单元，下标从 0 到 n-1。遍历用 `for` 循环，求最大值用“打擂台”，统计次数可以让数据本身充当下标。较大的数组应该声明为全局变量，既自动清零，也不会撑爆栈，并且要多开几个位置以防越界。
