# 一维数组

> [!目标]
> - 理解数组：一排连续的“盒子”，下标从 0 开始
> - 会声明、赋初值、读入、遍历、输出
> - 会用数组做最值、计数这两类最常见的事
> - 知道越界的危险，知道全局数组怎么开

## 数组是什么

要存 5 个人的成绩，难道声明 5 个变量 `s1、s2、s3、s4、s5`？存 100 个呢？**数组**就是把相同类型的一批数据，放在一排连续的盒子里，用同一个名字，靠**编号（下标）**区分。

```cpp frag
int a[5]={10,20,30,40,50};
cout<<a[0]<<" "<<a[4]<<endl;
a[2]=99;
cout<<a[2]<<endl;
```

```output
10 50
99
```

| 下标 | 0 | 1 | 2 | 3 | 4 |
| :-: | :-: | :-: | :-: | :-: | :-: |
| 值 | 10 | 20 | 30 | 40 | 50 |

声明 `int a[5]` 的意思是：造 5 个能装 `int` 的盒子，名字叫 `a`。**下标从 0 开始**，所以 5 个盒子的下标是 0 到 4，**没有 `a[5]`**。

## 赋初值

```cpp frag
int a[5]={1,2,3};
for (int i=0;i<5;i++){
    cout<<a[i]<<" ";
}
cout<<endl;
```

```output
1 2 3 0 0
```

给了几个，就从前往后放几个，**没给的自动补 0**。所以 `int a[100]={0};` 是把整个数组清零的常见写法。

## 读入、遍历、输出

读入 `n` 个数，再倒着输出：

```cpp title="reverse.cpp"
#include <bits/stdc++.h>
using namespace std;
int main(){
    int n;
    int a[105];
    cin>>n;
    for (int i=0;i<n;i++){
        cin>>a[i];
    }
    for (int i=n-1;i>=0;i--){
        cout<<a[i]<<" ";
    }
    cout<<endl;
    return 0;
}
```

```input
5
1 2 3 4 5
```

```output
5 4 3 2 1
```

**用 `for` 配合下标遍历数组**，是数组最基本的用法：`i` 从 0 走到 `n-1`。

## 经典用法一：找最大值（打擂台）

先假设第一个数最大，再一个一个和它比，有更大的就换上去，像擂台一样。

```trace
int a[3]={5,2,8};                 //@s1
int mx=a[0];                      //@s2
for (int i=1;i<3;i++){            //@s3
    if (a[i]>mx){                 //@s4
        mx=a[i];                  //@s5
    }
}
cout<<mx;                         //@s6
---
s1 | a=[5,2,8] |  | 数组里有三个数。
s2 | a=[5,2,8]; mx=5 |  | 擂台：先让第一个数 a[0] 当擂主，mx 是 5。
s3 | a=[5,2,8]; mx=5; i=1 |  | 从第二个数开始挑战。
s4 | a=[5,2,8]; mx=5; i=1 |  | a[1] 是 2，2>5 吗？不成立，擂主不变。
s3 | a=[5,2,8]; mx=5; i=2 |  | 下一个挑战者。
s4 | a=[5,2,8]; mx=5; i=2 |  | a[2] 是 8，8>5 吗？成立。
s5 | a=[5,2,8]; mx=8; i=2 |  | 8 打赢了，成为新擂主，mx 变成 8。
s3 | a=[5,2,8]; mx=8; i=3 |  | i 变成 3，3<3 不成立，挑战结束。
s6 | a=[5,2,8]; mx=8 | 8 | 输出最大值。
```

找最小值同理，把 `>` 换成 `<`。求和、求平均值就是在遍历的同时累加。

## 经典用法二：计数

“某个数出现了几次”，可以让**数的本身当下标**，用一个计数数组记录：

```cpp title="count.cpp"
#include <bits/stdc++.h>
using namespace std;
int cnt[105];
int main(){
    int n,x;
    cin>>n;
    for (int i=0;i<n;i++){
        cin>>x;
        cnt[x]++;
    }
    for (int v=1;v<=3;v++){
        cout<<v<<" 出现了 "<<cnt[v]<<" 次"<<endl;
    }
    return 0;
}
```

```input
6
1 3 1 2 3 1
```

```output
1 出现了 3 次
2 出现了 1 次
3 出现了 2 次
```

`cnt[x]++` 就是：找到编号为 `x` 的盒子，里面的数加 1。这个技巧叫“**桶**”，在竞赛里非常常见。

## 全局数组：竞赛里的标准做法

注意上面 `cnt` 声明在 `main` **外面**，这叫**全局变量**。它有两个好处：

1. **自动清零**：全局的数组和变量，一开始全是 0，不用手动初始化。
2. **空间足够**：函数里面声明的变量放在一个很小的区域里（栈），数组开得太大，程序会直接崩溃；全局的放在另一块大空间里，开得下几百万个 `int`。

所以竞赛里的标准写法是：

```cpp noverify
const int N=100005;     // 比题目的数据范围多开几个
int a[N];               // 全局数组，自动全是 0
```

> [!竞赛] 数组要“多开几个”
> 题目说 `n≤100000`，就开 `100005` 甚至 `100010`。多开一点点内存，不会超限；少开一个，就可能越界，导致答案错或程序崩溃。

## 数组的清零和填充

```cpp frag
int a[5];
fill(a,a+5,7);
memset(a+1,0,sizeof(int)*2);
for (int i=0;i<5;i++){
    cout<<a[i]<<" ";
}
cout<<endl;
```

```output
7 0 0 7 7
```

- `fill(a,a+n,v)`：把前 `n` 个盒子全填成 `v`。
- `memset(a,0,sizeof(a))`：把整个数组清零，用来清零最方便。**它是按字节填的，只适合填 0 或 -1**，别拿它填 1。
- `sizeof(a)/sizeof(a[0])`：数组一共有几个元素。

## 越界：数组最危险的错误

访问 `a[5]`（只有 0 到 4）、`a[-1]` 这类**超出范围的下标**叫“越界”。C++ **不会替你检查**，也不会报错，程序可能照常运行，也可能莫名其妙崩溃，或者悄悄改坏了旁边变量的值。

```cpp noverify
int a[5]={1,2,3,4,5};
cout<<a[5];     // 越界！a 只有 a[0]~a[4]
```

遇到“本地运行没问题，提交后却答案错 / 运行错误”，先检查数组有没有越界。

> [!思考] 求 3、5、8、4、10 的平均数
> 把五个数放进数组，遍历求和，再除以个数。

> [!答案] 参考写法
> ```cpp frag
> int a[5]={3,5,8,4,10};
> int sum=0;
> for (int i=0;i<5;i++){
>     sum+=a[i];
> }
> cout<<sum/5<<endl;
> ```
>
> ```output
> 6
> ```
>
> 如果平均数不是整数，要换成 `1.0*sum/5` 才不会丢掉小数。

> [!小结]
> - 数组 = 一排连续的盒子，下标 0 到 n−1，用 `for` 遍历。
> - 打擂台找最值、用下标当桶来计数，是两个最常用的套路。
> - 大数组声明成全局变量，会自动清零，也不会爆栈；要多开几个，别越界。
