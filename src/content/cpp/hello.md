# 第一个程序

> [!目标]
> 读完这一课，你应该能看懂一个最简单的 C++ 程序，说出其中每一行的作用，并且能自己改动它输出的内容。

## 一个最小的 C++ 程序

学习任何一门编程语言，第一个程序几乎都是让屏幕显示一句问候。下面这个程序做的就是这件事。

```cpp title="hello.cpp"
#include <bits/stdc++.h>
using namespace std;
int main(){
    cout<<"Hello, World!"<<endl;
    return 0;
}
```

运行之后，屏幕上会出现这样一行文字：

```output
Hello, World!
```

> [!提示] 暂时不需要安装任何软件
> 这一课只要求读懂程序。等到真正开始做题时，洛谷的题目页面自带代码提交框，把代码粘贴进去就能得到评测结果，所以不必急着在自己的电脑上配置开发环境。

## 逐行解读

整个程序只有六行，每一行承担的任务不同：

| 行 | 代码 | 作用 |
| :-: | :-- | :-- |
| 1 | `#include <bits/stdc++.h>` | 把标准库里的工具一次性引入进来，包括输入输出、数学函数、排序等，后面才能直接使用它们。 |
| 2 | `using namespace std;` | 声明这些工具都来自标准库。有了这一句，就可以直接写 `cout`，而不必每次都写成 `std::cout`。 |
| 3 | `int main(){` | 程序的入口。无论程序有多长，运行时都从 `main` 的第一条语句开始。 |
| 4 | `cout<<"Hello, World!"<<endl;` | 把引号里的文字输出到屏幕，`endl` 表示输出之后换行。 |
| 5 | `return 0;` | 告诉操作系统程序正常结束。 |
| 6 | `}` | 与第 3 行的 `{` 配对，标出 `main` 的范围。 |

## 程序是怎样一步步执行的

程序的执行顺序是固定的：从 `main` 开始，把花括号里的语句自上而下逐条执行。点击播放，可以看到每执行一步，代码的高亮位置和屏幕上的输出会一同变化。

```trace
#include <bits/stdc++.h>
using namespace std;
int main(){                          //@s1
    cout<<"Hello, World!"<<endl;     //@s2
    return 0;                        //@s3
}
---
s1 |  |  | 程序从 main 开始，花括号里的语句将按从上到下的顺序依次执行。
s2 |  | Hello, World!\n | 执行输出语句，屏幕上出现 Hello, World!，光标移到了下一行。
s3 |  |  | 执行到 return 0，程序到此结束。
```

## 书写时的几条规则

C++ 对格式的要求很严格，初学时最容易在下面三处出错。首先，每一条语句都要以英文的分号结尾，例如上面的 `cout…;` 和 `return 0;` 各是一条语句，漏掉分号就无法通过编译。其次，花括号必须成对出现，有 `{` 就要有对应的 `}`。最后，程序区分大小写，`Main` 和 `main` 是两个不同的名字；同时所有标点都要在英文输入法下输入，中文的引号、分号和括号都会导致报错。

## 注释

程序里可以写一些只给人看、编译器会直接忽略的文字，这就是注释。它的用途是说明一段代码在做什么，几个月后回头看自己写的程序时，注释往往比代码本身更有帮助。

C++ 有两种注释：`//` 从这两个斜杠开始直到行尾；`/* */` 可以跨越多行。

```cpp title="comment.cpp"
#include <bits/stdc++.h>
using namespace std;
int main(){
    // 这是单行注释，从两个斜杠到行尾都会被忽略
    cout<<"第一句"<<endl;   // 注释也可以接在一行代码的后面
    /* 这是多行注释，
       可以写很多行 */
    cout<<"第二句"<<endl;
    return 0;
}
```

```output
第一句
第二句
```

## 常见的编译错误

程序写错了，编译器会指出问题大致出在哪一行。刚开始最常见的是下面两种：

```text
error: expected ';' before 'return'
error: 'cout' was not declared in this scope
```

| 报错信息 | 通常的原因 | 处理方法 |
| :-- | :-- | :-- |
| `expected ';' before …` | 上一条语句的末尾漏了分号 | 检查报错那一行的**上一行** |
| `'cout' was not declared` | 缺少 `using namespace std;`，或者开头的头文件没有写 | 把程序最前面的两行补上 |

> [!思考] 动手改一改
> 把程序改成先输出你的名字，再换一行输出一句你想对自己说的话。

> [!答案] 参考写法
> 用两条 `cout` 语句，每条末尾都用 `endl` 换行：
>
> ```cpp frag
> cout<<"我是小明"<<endl;
> cout<<"我一定能学会 C++"<<endl;
> ```

> [!小结]
> C++ 程序从 `main` 开始，按顺序逐条执行；开头固定写头文件和 `using namespace std;`，每条语句以分号结束，花括号成对出现。注释不会被执行，只是写给读程序的人看的。
